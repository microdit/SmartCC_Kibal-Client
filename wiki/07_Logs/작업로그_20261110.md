## 시간순 기록

1. **웹 부팅 결함 수정** — `web/` `"type":"module"` ↔ CommonJS 충돌: `postcss.config.js`, `tailwind.config.js` → `.cjs` 리네임. Vite 서빙 정상 (`https://192.168.11.22:5173`, 이 Mac 실IP 확인 — `.39`는 DEV Asterisk 서버이므로 5173 거부가 정상)
2. **SIP 등록 취약 구조 개선(1차)** — 수동 등록 방식(`register:false` → 별도 `register()`)이 첫 WS `Connection refused` 시 init 실패 후 REGISTER 누락. `UaSettings.register=true` 자동등록 전환 + `register()` 상태 가드. 실측 `registered => 200 OK`
3. **1:1 영상 실기 검증** — `tool/call_probe.dart` 양측 `REMOTE STREAM video=1 audio=1` CALL_OK. 3자 회의 `CONFERENCE_OK` (3자 모두 video=1). Intel Mac 결과(음성) 대비 영상 경로 실동작 확정
4. **AppLogger 인프라 신설** — `lib/src/utils/app_logger.dart`: 파일 영구 기록(컨테이너 내 `Application Support/com.microdit.macosClient/logs/app.log`, 직전 세션 `app-prev.log`, 2MB 자동 rotate), FlutterError/UnhandledError 글로벌 후커, **5초 스팸 방지(동일 로그 요약)** — 2MB 오버플로로 INFO 유실됨을 규명
5. **네이티브 로그 뷰어 메뉴** — `창 > 실행 로그 보기` (⌥⌘L). NSTextView 실시간 폴링(1초)/자동 스크롤/Find Bar/폴더에서 열기/전체 복사. 첫 시도(코드 등록) 불발 → **MainMenu.xib에 정의 확정** (programmatic 등록 미출력 원인)
6. **통화화면 PIP 렌더 결함 수정** — `Positioned(right:16,bottom:124)`가 Column 내부에 있어 `ParentDataWidget` 오류 1초마다 반복 + PIP가 컨트롤 버튼과 겹침 → 외부 Stack 직계 재구조화. 유저 확인: "오른쪽 하단에 잘 보임"
7. **CallScreen dispose 결함** — deactivated 위젯에서 `Provider.of` 접근 → initState 참조 저장 방식 교체
8. **등록 실패/성공 불일치 개선(2차)** — `init()` 폴링: 15초 내 connected **또는 registered** 관찰 시 성공 처리. 이전에는 첫 WS 실패 → 즉시 실패 리턴, UA 자동 재연결이 등록해도 UI는 실패 표시하는 뒤틀림
9. **배포 산물 갱신** — Release 재빌드 + DMG 재패키징 (`Release/macos_client.dmg`)
10. **커밋/푸시** — git-sync 3-way (github 성공, dev/prd는 기 알려진 NAS 경로 문제로 실패)
