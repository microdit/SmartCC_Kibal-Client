# 작업로그 2026-11-26

## 6700 재입장 원격 트랙 누적 근본 수정

- 원인: 11/17 v0.0.37은 SIP BYE만 정리, `sip_client.dart::_cleanupSession()`이 `MediaManager._remoteSessions` 미정리. 재입장마다 원격 MediaStream 누적 → `Track is nil` 32건 → 408 RTP Timeout.
- 수정: `SipProvider.onCallEnded` 콜백, `KibalApp` 연결, `MediaManager.clearRemoteSessions()` 공개(dispose 재사용), 동기화 단계에서 원격 트랙 3개 제한, `MediaProvider.clearRemoteSessions()` 래퍼.
- 검증: flutter analyze No issues, flutter test 17/17, Release DMG codesign OK.

## 버전 번호 역행 사고 및 복구

- 사고: 위 수정 커밋(`aac71569`)에서 `pubspec.yaml` 버전을 `0.0.63+64` → `0.0.58+58`로 **잘못 역행**시킴. 상위 버전 커밋(df9432cc v0.0.63+64, 811066b6 v0.0.62, 1908f5ba v0.0.61 등)은 삭제되지 않고 브랜치에 남아 있음.
- 영향: 로컬/origin HEAD=`aac71569`(v0.0.58), dev/prd HEAD=`df9432cc`(v0.0.63+64). 단말이 이전 버전으로 인식 가능.
- 조치: `version: 0.0.64+65`로 복구(최신 0.0.63+64의 다음 버전), Info.plist 동기화, 재빌드/재배포, origin→dev→prd 3-way 푸시.
- 재발 방지: 빌드 전 `git show <remote>/<branch>:macos-client/pubspec.yaml`로 최신 버전 확인 후 +1 규칙 적용.
