# 작업인계 — A10 T0-C SIP / USB BYOD (2026-11-12)

**기준 시각**: 2026-11-12 19:05 KST
**상태**: T0-C SIP 저장·등록 미완료 / USB B′ 링크 미성립 / P1·P2 실기 대기
**상세**: [[wiki/06_Reports/20261112_A10_T0C_USB_중간보고서_v1.0]] · **계획**: [[docs/보고서/20261112_A10_T0C_USB_작업계획서_v1.0]]

---

## 1. 한 줄 요약

A10은 BYOD 전용이며, USB-C를 연결했지만 Mac에서 Yealink 장치가 열거되지 않는다. A10 화면의 `No sharing signal`은 화면 공유 신호 기준이며, P1 카메라/오디오 판정은 Mac의 USB 열거로 한다. SIP T0-C는 A10의 `talking=true` 때문에 `writeconfig`가 발생하지 않아 저장되지 않았다.

---

## 2. 현재 확인된 상태

| 구분 | 상태 |
|------|------|
| A10 | `192.168.0.12`, TEAMS EDITION, FW `278.320.0.86`, `byod` only |
| A10 SIP | `account.sip=0`, `1201` 미등록 |
| A10 talking | `true` (`/api/common/info/status/talking`) |
| A10 화면 | BYOD, `Yealink Room Camera`/`Room Audio`, `No sharing signal` |
| USB-C | 후면 C-type 포트에 연결, LED 점등 |
| Mac | Mac Pro 7,1, macOS 26.7.1, Yealink 미열거, `HD20K`만 USB 오디오 |
| 서버 | `192.168.0.3`, `1201 Unavailable`, `1101/1103 Avail`, `6100 follow_talker` 로드 |
| 클라이언트 | v0.0.21 P1, v0.0.22 P2 빌드 완료, 실기 대기 |

## 3. 바로 이어서 할 일

1. **USB-C 케이블 확인**
   - USB-C → USB-C 데이터 케이블인지 확인 (충전 전용 금지)
   - Mac Pro 상단 Thunderbolt 3 포트에 직결, 허브/변환 제거
   - macOS `Privacy & Security > Allow accessories to connect` 확인
2. **Mac 열거 확인**
   ```bash
   ioreg -p IOUSB -l -w 0 | grep -i -E 'yealink|room camera|room audio'
   system_profiler SPAudioDataType | grep -i -A6 -E 'yealink|hd20k'
   ```
   - Yealink가 보이면 v0.0.21 P1 실기(장치 선택 → 1:1/6000) 진행
3. **USB가 계속 안 되면 SIP T0-C 재시도**
   - USB-C 분리 후 `talking=false` 확인
   - SIP Account 입력 시 `fill + Tab`으로 모델 갱신
   - `Confirm` 후 `POST /api/inner/writeconfig` 발생 확인
   - A10 `Registered` + 서버 `1201 Avail` 확인
4. **둘 다 실패 시**
   - 케이블/포트/펌웨어 하드웨어 이슈로 에스컬레이션
   - A10 모드 변경(공장 초기화)은 하지 않는다.

## 4. 재현 명령

```bash
# A10
A10_PASS='<관리자 비밀번호>' ./scripts/a10_admin.sh summary
A10_PASS='<관리자 비밀번호>' ./scripts/a10_admin.sh get '/api/common/info/status/talking'
A10_PASS='<관리자 비밀번호>' ./scripts/a10_admin.sh get '/api/account/status?type=sip&acc=1'

# 서버
docker exec kibal-dev-asterisk asterisk -rx 'pjsip show contacts'
docker exec kibal-dev-asterisk asterisk -rx 'pjsip show endpoint 1201'
docker exec kibal-dev-asterisk asterisk -rx 'confbridge show profile bridge kibal_bridge_ft'
```

---

## 5. 주의사항

- 관리자 비밀번호는 변경·기록하지 않는다.
- A10 모드 변경은 공장 초기화를 동반하므로 금지한다.
- T0-C는 SIP 필드만 변경하는 가역 테스트다. 실패 시 원복한다.
- `talking=true` 상태에서는 저장이 조용히 무시되므로, `writeconfig` 요청이 없으면 먼저 `talking`을 확인한다.
- 증거 캡처 시 인증·비밀번호·토큰을 마스킹한다.
