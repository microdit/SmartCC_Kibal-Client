## 1. SIP 등록 실패 문제 분석

### 1.1 증상
- Web Client에서 `1101`/`1102` 번호로 SIP 등록 시도 시 `미등록` 상태 표시
- 콘솔 로그에 `status code 500` (1101) 및 `status code 401` (1102) 반복 발생
- WebSocket 연결은 성공하지만 등록 실패

### 1.2 원인 분석

#### 1.2.1 1101 번호 (status code 500)
- Asterisk pjsip.conf에 plain text 비밀번호(`1101pass`)로 변경 완료됨
- 하지만 `/opt/kibal/config/pjsip.conf.template` 템플릿 파일이 재시작 시 MD5 해시로 재생성되어 설정이 초기화됨
- **핵심 이슈**: 템플릿 파일의 permanent 수정 필요

#### 1.2.2 1102 번호 (status code 401#### 1.2.2 1102 번호 (status code 401#### 1.2.2 1102 번호 (status code 401###8f8012caee1cbab300ded5840ea6d`) 보유
- Asterisk는 plain text(`1102pass`)를 expecting하지만, client가 MD5 해시 전송하여 인증 실패
- **핵심 이슈**: Docker env vars permanent 변경 필요

#### 1.2.3 연결 IP 불일치
- 1102 로그에 `192.168.11.2`로 연결 기록되나 서버는 `192.168.11.39`에 있음
- 네트워크 설정 또는 라우팅 문제 가능

### 1.3 현재 진행 상황
- ✅ `/web/.env` 파일 생성하여 Web Client SIP 설정 완료
- ✅ Running `/run/asterisk/pjsip.conf`에 plain text 비밀번호(`1101pass`~`1104pass`) 적용 확인됨
- ⚠️ 컨테이너 재시작 시 설정이 초기화되는 문제 존재 (템플릿 수정 필요)
- ⚠️ 1102 연결 IP(`192.168.11.2` → `192.168.11.39`) 불일치 문제 존재
