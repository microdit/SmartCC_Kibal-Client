# 작업로그 2026-11-27

## 클라이언트 로그 이중 저장 설계 반영

- OPS `POST /api/client-logs`로 전송된 로그를 서버 `ClientLogStore`에 저장的同时,
  마운트된 NAS SMB 경로(`/Volumes/NetBackup/보관함/개발/Live_Log/<ext>.txt`)에도 미러 저장하도록 설계.
- 제약: NAS SMB는 내부망+마운트 상태에서만 사용 가능. 미마운트/외부망이면 OPS 저장만 유지하고 미러 실패 상태 기록.
- 서버 저장소 설계: [[wiki/02_Design/20261127_클라이언트로그_이중저장_설계서_v1.0]] (SmartCC_Kibal repo).
- 클라이언트는 기존 `RemoteLogForwarder`가 OPS로 전송 중이므로 별도 변경 없음, 서버 미러로 양쪽 저장 충족.
