## 16. C 후속 실기 검증 (23:15) — 발언자 1201 자동설정 확인

- 사용자 제공 1103 로그(`23:15:23~23:17:18`) + 1103 컨퍼런스 화면 캡처. **발언자가 1201(A10 회의실)로 자동설정**, 발언자 화면 활성화·큰 화면에 정상 표시, 음성 데이터 수신 중
- 1103 로그: `audioKB=143~150`, `audioPackets` +250/5s, `audioLost=0`, `videoKB=198~424`, `in=1920x1080@30fps`, `decodedFrames+792~869`, `keyframes 286→292`, `freeze=46`/`pli=1`/`nack=2`/`vLost=0` 고정(누적 카운터 정상), `ice=Completed`, `out=1280x720@30fps target=2500kbps limit=none`
- 화면: `회의실 6100 · 참가자 2명 · 발언자 화면`, 카드 `발언자 영상`(선택) / `A10 회의실(1201)` / `나·경기도지사(1103)`
- 서버 재계측: `kibal_bridge_ft` `Video Mode: follow_talker`, `Video Update Discard: 2000`, `REMB Send Interval: 0`, `Enable Events: no`. `confbridge list 6100` Flags **여전히 빈 값**. `1103` 채널 `NativeFormats (opus|h264)`, `video-1 sendrecv/h264`, `Group: 0`, `BRIDGEPEER=…PJSIP/1201-00000010`, Elapsed 2h22m48s. `1201` `Group: -1`
- **정정**: 직전 "Flags 빈 값 = 발화자 미선정 → 후보 ① 발화자 영상 미전달 유력"은 **오진 기각**. ConfBridge `list` Flags는 talker를 표시하지 않으며, `Enable Events: no`는 AMI 이벤트 설정이라 영상 전달과 무관 → **`confbridge.conf` 변경 불필요**
- **C4 판정**: ① 기각 / ② 자기 루프백·③ `max_video_streams=1` 잔여. 모든 증거가 **A10→1103 방향**이고 최초 증상 "A10 원격 영상 미표시"는 **1103→A10 방향**이라 아직 미검증
- **C 잔여 2건**: A10(1201) 실제 화면 캡처 / 발화자를 1103으로 전환해 A10에 1103 영상이 뜨는지. 실기 의존이므로 A로 먼저 넘어가도 무방
