`wiki/04_Prompts/20261109_macbook_agent_후속작업프롬프트.md`에 따라 MacBook Pro에서 영상 실기 검증 수행:

1. **환경** — Flutter 3.47.9 / CocoaPods 1.17.0(brew) / DEV Asterisk 8088 연결 확인, `analyze` 0건 / `test` 全 PASS / Debug 빌드 성공
2. **REGISTER** — REGISTER_OK
3. **권한 이슈 발견** — 최초 call_probe CALL_FAIL: `getUserMedia`가 30초 무응답 → macOS TCC 카메라/마이크 권한 미승인 원인. 사용자 권한 허용 후 해결. 격리 확인용 `tool/gum_probe.dart` 신규 추가 → GUM_OK(video=1 audio=1)
4. **1:1 영상통화** — CALL_OK, 양측 `REMOTE STREAM video=1 audio=1` → **영상 송수신 실기 검증 완료**
5. **3자 회의** — CONFERENCE_OK, 3자 모두 `video=1` 원격 스트림 수신
6. **문서** — `docs/보고서/20261109_macOS테스트결과보고서_v1.0.md`에 §7(MacBook 검증) 추가
7. **웹 부팅 수정** — `web/`이 `"type":"module"`인데 postcss/tailwind config가 CommonJS라 Vite 크래시 → `.cjs` 리네임, dev 서버 정상 (`https://192.168.11.22:5173`)
8. **macOS UI 등록 실패 수정** — 첫 WS `Connection refused` 시 init 타임아웃 후 REGISTER가 다시 시도되지 않는 구조 문제. `sip_client.dart`를 자동등록(`register: true`) 전환 + `register()` 상태 가드. 실측 `registered => 200 OK` (Digest) 및 UI "등록됨" 확인
