## 3. 발견 이슈 및 근본 원인 분석

### 3.1 OPS 8091 간헐 hang (P0)

| 항목 | 내용 |
|------|------|
| 증상 | TCP OPEN, HTTP 0 bytes / 6s timeout. `/health`도 무응답 |
| 영향 | 인증·로그·주소록 전부 실패 |
| 근본 원인 | gunicorn 2 workers × 4 threads + SQLite `delete` 저널 모드 → DB 잠금 경합 |
| 해결 | Mac Pro: SQLite WAL 모드 + busy_timeout=10000 + autoheal 컨테이너 자동 재시작 |
| 검증 | 60개 동시 요청 60/60 HTTP 200, journal mode `wal` 확인 |
| 상태 | ✅ 해결 (모니터링 중) |

### 3.2 엔드포인트별 hang (P1)

hang 시 `/health`와 `/api/client/config`는 정상이지만 `/api/client/contacts`와 `POST /api/client-logs`만 hang. 원인: contacts/client-logs가 DB/파일 저장 경로를 사용하여 잠금 경합 발생. health/config는 DB 접근 없음.

### 3.3 HTTPS/HTTP 혼동 (P1)

OPS는 HTTP-only인데 외부 프로필/사용자 입력이 HTTPS를 사용 → hang. 클라이언트에서 `secureOps` 토글과 URL 입력을 HTTP로 정규화하여 해결.

### 3.4 NAS 방화벽 KR-only 차단 (P2)

NAS 방화벽 프로필 `smartcc2_202611120`의 eth0 규칙이 `ipList: ["KR"]`만 허용. 미국 VPN IP(149.22.84.143) 차단 → DSM 외부 접근 불가. 한국 IP 테더링으로 우회. US 추가 시 정상.

### 3.5 SIP auto-register password missing (P2)

오프라인 인증 시 주소록 미동기화 → `bound = null` → `sipPassword = null` → auto-register 실패. `AppConstants.devQuickAccounts` 폴백으로 해결.

### 3.6 5090/5091 포트 혼동 (P3)

사용자가 DSM 접근에 5090/5091을 사용했으나 NAS는 해당 포트 미리스닝 (DSM은 5000/5001). 포트포워딩만 걸려 있어 hang. 올바른 포트는 5000(HTTP)/5001(HTTPS).
