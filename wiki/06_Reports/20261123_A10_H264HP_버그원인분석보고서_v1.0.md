## 1. H.264 High Profile (HP) 개요

H.264/AVC는 프로파일별 기능 차이가 있습니다.

| 프로파일 | 주요 기능 | 용도 |
|---|---|---|
| Baseline (BP) | I/P 프레임, CAVLC | 모바일/저지연 |
| Constrained Baseline (CBP) | BP + 제약 (B-frame/8x8 변환 금지) | WebRTC 표준 |
| Main (MP) | B-frame, CABAC, 가중 예측 | 방송 |
| High (HP) | 8x8 변환, 양자화 매트릭스, CABAC | 고화질 회의/방송 |

A10은 **H.264 HP + H.264(Constrained Baseline)** 두 코덱을 활성화하고, HP를 우선 협상합니다. HP는 `profile-level-id = 42002a`(level 4.2)를 사용합니다.

## 2. 실패 원인

- 1:1 통화에서 A10이 HP로 offer → 클라이언트(WebRTC)는 Constrained Baseline(42e01f)으로 answer.
- Asterisk는 **영상 트랜스코딩 미지원** → 프로파일 불일치 시 simple_bridge가 RTP를 중계하지 못함.
- 결과: 미디어 트랙은 생성되나 `videoBytes=0`, 약 1.9초 후 A10이 BYE 전송.
- 6100 회의실은 ConfBridge가 중계/혼합하므로 A10 HP가 정상 동작 (대조군).

## 3. 구성 흐름

```
[1102 macOS] --WSS 8088--> [Asterisk 192.168.11.5] <--SIP/UDP 5060-- [A10 192.168.11.65]
       |                            |                                      |
       |  re-INVITE (simple_bridge) |                                      |
       |<---------------------------|                                      |
       |  SDP: CBP(42e01f)          |  SDP: HP(42002a)                     |
       |                            |                                      |
       |  videoBytes=0 (미수신)     |  BYE (1.9s 후)                       |
```

1. 1102 등록 (WSS)
2. A10 → Asterisk INVITE
3. Asterisk → 1102 re-INVITE (simple_bridge)
4. SDP 협상: HP vs CBP 불일치
5. 미디어 트랙 생성되나 RTP 미수신
6. A10 BYE

## 4. 아키텍처

```
┌─────────────┐     SIP/UDP 5060      ┌──────────────────┐     WSS 8088      ┌─────────────┐
│  A10        │ ────────────────────▶ │  Asterisk 22     │ ◀────────────── │  macOS 1102 │
│ 192.168.    │                      │  192.168.11.5    │                  │  v0.0.58    │
│ 11.65       │                      │  simple_bridge   │                  │             │
└─────────────┘                      └──────────────────┘                  └─────────────┘
                                            │
                                            │ ConfBridge 6100 (정상)
                                            ▼
                                     ┌─────────────┐
                                     │ A10 + 110x  │
                                     └─────────────┘
```

- Asterisk는 영상 트랜스코딩 미지원.
- 1:1은 simple_bridge 직접 중계 → 코덱/프로파일 일치 필수.
- 회의실은 ConfBridge 중계 → 프로파일 차이 흡수.

## 5. 코덱 연결

| 구간 | 오디오 | 비디오 |
|---|---|---|
| A10 ↔ Asterisk | G.722 / PCMA / PCMU | H.264 HP (우선) / H.264 |
| Asterisk ↔ 1102 | Opus / G.722 / PCMA / PCMU | H.264 Constrained Baseline |
| Asterisk allow | ulaw, alaw, g722, opus | h264 |
| ICE (LAN) | host candidate only (TURN 제외) | host candidate only |

## 6. 코덱 메트릭스

| 항목 | A10 | 1102 | 6100 회의 |
|---|---|---|---|
| 송출 코덱 | H.264 HP | H.264 CBP | H.264 HP |
| 해상도 | 최대 1080p | 720p (cap) | 1280x720 |
| 프레임레이트 | 30fps | 30fps (cap) | 30fps |
| 수신 videoBytes | 0 (1:1) | 0 (1:1) | >0 (정상) |
| videoTracks | 0/0 | 0/0 | 1/1 |
| 통화 유지 | 1.9s 후 BYE | 1.9s 후 BYE | 30분+ |
