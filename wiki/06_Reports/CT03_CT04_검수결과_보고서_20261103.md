```
1. 모바일 앱 실행
2. 설정 화면으로 이동
3. 서버 도메인: 192.168.11.2
4. 내선: 1001
5. 비밀번호: (PRD 비밀번호)
6. 전송 방식: UDP
7. 포트: 5060
8. 등록 버튼 클릭
9. ≡ 접근 권한 허용 (카메라, 마이크)
10. 등록 상태 확인: "등록됨"
11. Asterisk에서 contact 확인
   ssh nas2 'docker exec kibal-prd-asterisk asterisk -rx "pjsip show contacts"'
12. 기대 출력: 1001/sip:...;transport=UDP ... Avail
```

    ssh nas2 'docker exec kibal-prd-asterisk asterisk -rx "core show channels"'
