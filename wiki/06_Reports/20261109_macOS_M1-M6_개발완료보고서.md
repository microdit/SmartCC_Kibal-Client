## 1. 목적

웹 클라이언트의 근본 제약(카메라/마이크 사용 시 **HTTPS Secure Context**, **WSS 인증서**)과 iOS의 SIP 미동작(`flutter_sip` Android 전용)을 해결하기 위해 **macOS 네이티브 앱을 우선 완성**하고, 검증된 구조를 iOS/Windows/Android로 역적용한다.

## 2. 아키텍처 (확정)

```
macos-client (Flutter desktop)
 ├─ UI: LoginScreen / DialerScreen / CallScreen / ConferenceView / MacMainView
 ├─ Provider: SipProvider, MediaProvider
 ├─ SIP: KibalSipClient → sip_ua(dart-sip-ua) → ws://192.168.11.39:8088/ws
 └─ Media: MediaManager → flutter_webrtc (네이티브 WebRTC, DTLS-SRTP)
                ↓
        DEV Asterisk (kibal-dev-asterisk) — PJSIP + ConfBridge(6000)
```

- **HTTPS/WSS 인증서 불필요**: 브라우저가 아니므로 평문 WS 사용, 카메라/마이크는 OS 권한으로 처리
- **MD5 401 문제**: 프로토콜이 아닌 Docker env(비밀번호 MD5 해시) 설정 문제였음. DEV 평문 비밀번호로 해결 확인

| 파일 | 변경 |
|------|------|
| `lib/src/sip/sip_client.dart` | sip_ua 기반 전면 재작성 (등록/통화/이벤트/비디오 대체) |
