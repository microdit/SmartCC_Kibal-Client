### 4.2 P0: CT03 검증 (SIP 등록) (1-2시간)

**목표**: Mobile 앱이 Asterisk PRD 서버에 SIP 등록 성공

#### 4.2.1 UDP SIP 등록 테스트

** 설정:**
- 내선: `1001`
- 비밀번호: (PRD 비밀번호)
- 도메인: `192.168.11.2`
- 포트: `5060`
- 전송 프로토콜: `UDP`

** 절차:**
1. 앱 실행
2. SIP 계정 입력
3. 등록 버튼 클릭
4. 앱 상태가 "등록됨"으로 표시되는지 확인
5. Asterisk에서 contact 확인

** 검증 명령어:**
```bash
# Asterisk contact 확인
ssh nas2 'export PATH=/usr/local/bin:$PATH; docker exec kibal-prd-asterisk /usr/sbin/asterisk -C /run/asterisk/asterisk.conf -rx "pjsip show contacts"'
# 기대 출력: 1001/sip:1001@...;transport=UDP ... Avail
```

#### 4.2.2 WebSocket SIP 등록 테스트

** 설정:**
- 내선: `1101`
- 비밀번호: (PRD 비밀번호)
- 도메인: `192.168.11.2`
- WebSocket 서버: `ws://192.168.11.2:8088/ws`
- 전송 프로토콜: `WebSocket`

** 절차:**
1. 앱 실행
2. SIP 계정 입력 (WebSocket 설정)
3. 등록 버튼 클릭
4. 앱 상태가 "등록됨"으로 표시되는지 확인
5. Asterisk에서 contact 확인

** 검증 명령어:**
```bash
# Asterisk contact 확인
ssh nas2 'export PATH=/usr/local/bin:$PATH; docker exec kibal-prd-asterisk /usr/sbin/asterisk -C /run/asterisk/asterisk.conf -rx "pjsip show contacts"'
# 기대 출력: 1101/sip:1101@...;transport=WS ... Avail
```

#### 4.2.3 합격 기준

- ✅ REGISTER 200 OK 응답
- ✅ Asterisk `pjsip show contacts`에 contact 확인
- ✅ 등록 해제 후 contact 제거
- ✅ 앱 콘솔에 인증 오류 없음
- ✅ **증거**: 앱 스크린샷, `pjsip show contacts` 출력

### 4.3 P0: CT04 검증 (1:1 영상통화) (1-2시간)

**목표**: Mobile 단말 2대에서 1:1 영상통화 성공

#### 4.3.1 Mobile ↔ Mobile 통화 테스트

** 준비:**
- 단말 A: `1001` (UDP) 또는 `1101` (WebSocket) 등록
- 단말 B: `1002` (UDP) 또는 `1102` (WebSocket) 등록

** 절차:**
1. A에서 1002 (또는 1102)로 호출
2. B에서 수신
3. 양쪽 세션 Established 확인
4. 양방향 오디오/영상 확인
5. A에서 종료
6. 양쪽 세션 정리 확인

** 서버 확인:**
```bash
# 채널 확인
ssh nas2 'export PATH=/usr/local/bin:$PATH; docker exec kibal-prd-asterisk /usr/sbin/asterisk -C /run/asterisk/asterisk.conf -rx "core show channels"'

# RTP 통계 확인
ssh nas2 'export PATH=/usr/local/bin:$PATH; docker exec kibal-prd-asterisk /usr/sbin/asterisk -C /run/asterisk/asterisk.conf -rx "pjsip show channelstats"'
```

#### 4.3.2 Mobile ↔ Web 통화 테스트 (보조)

** 준비:**
- Mobile: `1001` (UDP) 등록
- Web: `1102` (WebSocket) 등록

** 절차:**
1. Mobile에서 1102로 호출
2. Web에서 수신
3. 양방향 오디오/영상 확인

#### 4.3.3 합격 기준

- ✅ 양쪽 세션 Established
- ✅ 양방향 오디오/영상 확인
- ✅ H.264 코덱 협상
- ✅ RTP 송수신 확인
- ✅ 종료 후 채널 해제
- ✅ **증거**: 양쪽 단말 스크린샷, Asterisk 채널/RTP 출력, `sngrep` 캡처
