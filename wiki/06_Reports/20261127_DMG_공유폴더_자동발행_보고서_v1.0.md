- 문서번호: `KIBAL-CLIENT-DMG-PUBLISH-20261127-v1.0`
- 작성일: 2026-11-27 KST
- 상태: 구현·검증 완료(TEST), 다단말 재현 검증 잔여
- Client 구현 커밋: `5420f62f`
- Client 브랜치: `test/client-v0.0.64-recovery`
- Server 문서 브랜치: `test-pending-log-sync`

## 1. 배경

기존 `release_macos.sh`는 빌드를 실행한 Mac의 로컬 경로에만 DMG를 생성했다. MacPro·MacBook·MacBookAir 중 어디서 빌드했는지에 따라 산출물 위치가 달라, 공유폴더에 DMG가 있는 것으로 오해하거나 수동 복사 과정에서 버전/체크섬 혼란이 발생했다.

이번 작업은 빌드와 공통 발행을 하나의 기본 흐름으로 묶어, 어느 Mac에서 빌드하더라도 동일한 NAS 공유폴더 규칙을 사용하도록 했다.

## 2. 구현 내용

### 2.1 신규 공통 발행 스크립트

- 파일: `macos-client/scripts/publish_macos_dmg.sh`
- 역할:
  - 로컬 Release DMG의 버전/파일명/SHA256 확인
  - NAS 공유폴더에 임시 파일로 복사 후 `mv`하여 발행
  - 복사 후 공유폴더 DMG의 SHA256 재검증
  - 동일 버전 `.sha256` 파일 발행
  - `macOS_Client_LATEST.txt`에 최신 버전/파일/SHA256/빌드 호스트/발행 시각 기록

### 2.2 릴리스 스크립트 연동

- 파일: `macos-client/scripts/release_macos.sh`
- 기본 동작: 빌드·서명·DMG 검증·체크섬 후 공유폴더 자동 발행
- 로컬 전용 옵션: `--no-publish`
- 공유폴더 경로 override: `KIBAL_DMG_SHARE_DIR`
- 미마운트/쓰기 불가:
  - 빌드 결과는 유지
  - `SKIP(NAS 미마운트/쓰기 불가)` 명시
  - 로컬 DMG만 생성되었음을 출력
- `--help`가 내부 `cd` 이후에도 동작하도록 절대 경로로 수정

### 2.3 git-pull 보고 연동

- 파일: `scripts/git-pull.sh`
- 발행 보고에 로컬 DMG와 별개로 **공통 DMG 경로/SHA256**을 추가
- 공유폴더에 파일이 없으면 `없음(공유 발행 전)`으로 명시

## 3. 공통 발행 규칙

| 항목 | 값 |
|---|---|
| 기본 공유폴더 | `/Volumes/NetBackup/보관함/개발/Live_Log` |
| DMG 파일명 | `macOS_Client_v<X.Y.Z>.dmg` |
| 체크섬 파일 | `macOS_Client_v<X.Y.Z>.dmg.sha256` |
| 최신 발행 정보 | `macOS_Client_LATEST.txt` |
| 로컬 DMG | `macos-client/build/macos/Build/Products/Release/macos_client_v<X.Y.Z>.dmg` |

- 공유폴더가 없으면 임의로 로컬 디렉터리를 만들지 않는다.
- 같은 버전을 다시 빌드하면 동일 버전 공유 DMG를 최신 빌드 결과로 교체한다.
- 버전 번호는 자동으로 상향하지 않는다. 기존 릴리스 가드와 TEST 브랜치 규칙을 그대로 적용한다.

## 5. 운영 사용법

```bash
cd /Users/microdit/Downloads/dev/SmartCC_Kibal-Client/macos-client
./scripts/release_macos.sh --no-bump
```

- NAS SMB이 마운트되어 있으면 자동으로 공통 DMG/체크섬/LATEST 파일이 갱신된다.
- NAS가 보이지 않으면 빌드는 완료되지만 공유 발행은 `SKIP`된다.
- 로컬 빌드만 필요하면:

```bash
./scripts/release_macos.sh --no-bump --no-publish
```

- 다른 Mac에서는 최신 스크립트를 받은 뒤 사용한다.

```bash
git fetch origin
git pull --ff-only origin test/client-v0.0.64-recovery
```

## 6. 남은 리스크/후속

- MacBook·MacBookAir에서 실제 SMB 마운트 → 빌드 → 자동 발행 재현 검증은 아직 수행하지 않았다.
- 공유폴더 자동 발행은 파일 배포일 뿐, DEV 승격이나 6700 실기 PASS를 대체하지 않는다.
- v0.0.66은 TEST 산출물이다. 1102 로그에 `408 RTP Timeout / ICE Connection Failed`가 있어 운영 배포용 승격은 보류한다.
- NAS `dev/prd` Git remote는 SSH 4949 미도달로 이번 작업과 무관하게 SKIP 상태다.
