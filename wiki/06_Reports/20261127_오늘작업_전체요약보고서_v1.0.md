## 9. 차단/주의 사항

- NAS SSH 4949는 에이전트 셸에서 timeout. 다른 포트 추측 금지, `dev/prd` push SKIP.
- Server feature의 무관 수정/untracked는 별도 이슈로 분리.
- active call이 있으면 파괴적 정리/재시작 금지.
- `git add -A`, 승인 없는 force push, 버전 임의 상향 금지.
- DMG 자동 발행은 배포 파일 복사이며 DEV 승격 증거가 아니다.
