## 2. 변경 내역

### 서버 (SmartCC_Kibal, OPS 재빌드·배포 완료)
- `GET /api/conference/<room>/participants?extension=` — confbridge list + 채널 스트림 파싱(`has_video`, `video_order`, `self`, `display_name`)
- `POST /api/client/profile` — 표시 이름 저장(`client-logs/profiles.json`)
- `parsers.py` `parse_confbridge_channels`, `parse_channel_streams` + 단위 테스트
- 입력 검증: room `^\d{3,6}$`, 채널 `^PJSIP/[0-9A-Za-z_.-]+$`

### 클라이언트 (v0.0.18)
- `utils/conference_participants.dart` 신규: 표시 이름 보고, 회의 중 5초 폴링, 변경 시 `CONFERENCE participants` 로그
- `sip_client.dart`: 로그인 시 `reportProfile`
- `conference_screen.dart`: 참가자 기반 카드, 영상 스트림 매핑, 영상 없음/카메라 없음/준비중 상태, 이름 배지, OPS 실패 시 `참가자 N` 폴백

## 5. 제약 / 후속

- 같은 내선 중복 로그인 시 `self` 판정이 내선 기준이라 같은 내선의 다른 단말 카드가 숨겨질 수 있음 → 단말별 내선 고정 운영
- 원격 스트림 ↔ 참가자 매핑은 서버 m-line 순서 기반. 라벨 불일치 발견 시 msid 매핑으로 전환 검토
- 1:1 통화 화면(`call_screen.dart`)의 "원격 영상" 라벨은 이번 범위 외
