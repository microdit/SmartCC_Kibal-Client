- 작성일: 2026-11-22 KST
- 증상: 1104(외부망) 6700/6100 입실 시 원격 영상·음성 수신 0, 약 15초 후 `408 RTP Timeout / ICE Connection Failed`.

## 2. 근본 원인

1. **`ServerConfig.toJson()`이 `turn`을 저장하지 않음** → 앱 재시작 시 `ServerConfig.load()`로 복원된 `current.turn`이 `null`.
2. **autoRegister가 OPS config fetch보다 먼저 SIP를 초기화**(`_bootstrap`: `_checkForUpdate` → `_autoRegisterSip` 순서이나 lifecycle resume 경로에서 config 갱신 없이 autoRegister 호출). `current.turn=null` 상태로 `SipConfig.webrtc(turn: null)` 생성 → ICE servers에 STUN만 포함.
3. 이후 config fetch가 성공해도 `changed=false`(주소/version 동일)여서 SIP 재초기화가 발생하지 않아 TURN이 반영되지 않음.

> OPS split-horizon 자체는 정상(공개 Host 요청에 `turns:appletreeda.synology.me:5349` 반환 확인). 문제는 **클라이언트가 받은 TURN을 유지·적용하지 않은 것**.

## 3. 수정 내용 (v0.0.56)

- `macos-client/lib/src/utils/server_config.dart`
  - `toJson()`: `turn`을 설정 파일에 저장(시간제 HMAC 자격증명이라 캐시 무방).
  - `_fromJson()`: 저장된 `turn` 복원.
  - autoRegister 경로에서 `current.turn`이 유지되어 ICE에 TURN 포함.
- `macos-client/lib/src/ui/home/address_book_screen.dart`
  - `_autoRegisterSip()` 시작 시 `ServerConfigService.instance.refreshSmart()`를 먼저 수행해 최신 OPS config(TURN 포함) 반영 후 SIP 초기화.
- `macos-client/lib/src/utils/server_config.dart`: 미사용 `_isInternalProfile` 제거(analyze warning 해소).
