## 1. 증상

- 1101이 6700 회의실에 입장해 30fps·`audioLost=0`으로 정상 통화 중이었다가 14:14:56 `SIP media stalled (20s no RTP)`가 발생하며 강제 종료됨.
- 이후 SIP 재등록이 5회 이상 반복 실패(`SIP 전송 연결 시간 초과`), 14:21:18 재입장 시도 시 `InvalidStateError`로 호출 실패.

---

## 2. 원인

### 2.1 미디어 스톨 오검출 (핵심)

`sip_client.dart`의 5초 통계 프로브는 누적 `bytesReceived` 합계를 `_stallTotalBase`와 비교한다. re-INVITE가 들어오며 WebRTC 통계 카운터가 초기화되자 총량이 **21.6MB → 14.7MB로 감소**했다. 코드는 감소를 "수신 없음"으로 해석해 `_stallTicks`를 증가시켰고, 실제로는 바이트가 계속 증가했는데도 20초 후 스톨을 선언했다.

### 2.2 재진입 경합

스톨 이벤트를 받은 주소록 화면이 `sip.connect()`로 강제 재초기화를 실행했다. 재등록 직후 `mediaStalled` 플래그가 남아 있어, 사용자가 6700 재입장을 누른 순간 다시 re-init이 실행되면서 `callInitiation`이 등록 전 상태로 시작되어 `InvalidStateError`가 발생했다.

## 3. 수정

| 파일 | 변경 |
|------|------|
| `lib/src/sip/sip_client.dart` | 누적 바이트가 **감소**하면 카운터 리셋으로 보고 `_stallTotalBase`를 재설정하고 `_stallTicks`를 0으로 되돌림. 증가할 때만 정상 수신으로 처리. |
| `lib/src/providers/sip_provider.dart` | `connect()` 시작 시와 `call()` 시작 시 `_mediaStalled=false`로 초기화해 오래된 스톨 플래그가 재진입을 막지 않도록 함. |
| `lib/src/ui/conference/conference_screen.dart` | `isConnecting` 중 자동/수동 입장을 차단하고 안내 snackbar 표시. |
