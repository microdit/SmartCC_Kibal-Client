## 2. 외부망 접근 (도구 egress 기준)

`webfetch` egress IP는 `211.253.173.236`으로 확인되어 **완전한 해외 IP 관점은 아님**. WAN 측 규칙 검증으로 해석한다.

| 대상 | 결과 | 근거 |
|------|------|------|
| `https://appletreeda.synology.me:8089/httpstatus` | **PASS** | Asterisk 22.8.1, TLS Bind 0.0.0.0:8089 |
| `https://appletreeda.synology.me:8089/ws` | **PASS** | HTTP 426 Upgrade Required |
| `http://211.253.173.236:8091/health` | **PASS(복구 후)** | `{"status":"ok"}` |
| `http://appletreeda.synology.me:8091/api/client/config` | **도달 확인** | HTTP 401(인증 요구) |
| `https://appletreeda.synology.me:8091/...` | TIMEOUT | OPS는 HTTP-only |
| `http://211.253.173.236:8088/httpstatus` | TIMEOUT | 의도적 미개방 |
| `https://211.253.173.236:8089/httpstatus` | 전송 오류 | 인증서 CN/SNI 불일치(도메인 사용 필수) |
