## 3. 종합 결론
1. **참가자 중복 카드/상태 혼선**: 동일 내선 채널/세션 중복(H5/G5 재발, 1201 2중·1102 일시 2중)이 참가자 스냅샷에 반영되어 UI 중복 및 재입장 시 타일/트랙 불안정(`remoteTiles=0`, `videoTracks=0/1`)을 유발한 정황.
2. **1103 영상 미수신(시나리오1)**: 서버 채널이 audio-only(Streams `audio-0`)로 관측되어 서버/협상 측 비디오 부재 가능성 높으나, 1103 실제 클라이언트 로그 미수집으로 단정 불가.
3. **1102 SIGABRT 크래시**: `IncomingVideoStreamQueue`에서 `toI420`→`CheckValidDimensions` fatal. W2 가드가 `toI420` 내부 실패를 막지 못하는 경로가 남아 있어 네이티브 렌더러 보강 필요.
