## 4. 실기 진입 체크리스트 (순서)

1. **1103(iMac)에 v0.0.24 설치 → 1103 로그인** → OPS `1103.meta.json` `app_version=v0.0.24` 확인
2. **1101(MacPro)에 v0.0.24 설치 → 1101 로그인** → `app_version=v0.0.24` 확인
3. **A10(1201) 재등록** → `pjsip show contacts`에서 `Avail` 확인
4. **T-F1**: `1103 → 1201` 1:1 발신
   - OPS `SIP codec policy target=1201 type=offer video=h264First`
   - 서버 양 leg `video-1 Formats (h264)` 정합, 신규 `Don't know how to send format` 0건
   - **A10 화면에 원격 영상 표시** + 셀프 영상·음성 유지
5. **T-F2**: 1101 재로그인 + 6000/6100 5분
   - `re-REGISTER` 로그 0, `SIP 등록 시간 초과` 0, 튕김 없음
6. **T-G3/T-G1**: 6100에 1201 먼저 → 스피너 확인 → 1103 추가 입장
   - 카드 갱신, 2번째 입장 시 스피너 해소
7. **T-G5**: 종료 후 `confbridge list 6100`의 `1201` 채널 1개
8. **회귀**: 6100 발언자 화면 / 6000 3자 / A5 등록 유지(`remove_existing=false`)

판정 표는 [[wiki/03_Guides/20261113_F1F2_G3_테스트절차서_v1.0]].
