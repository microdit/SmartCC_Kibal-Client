## 4. 일정·우선순위 원칙

- 병렬 금지: C의 회의 채널을 A·D·B가 공유하므로 **한 번에 하나의 항목만** 실기 변경한다.
- 각 항목 종료 시 통화를 완전히 종료하고 `pjsip set logger off`·설정 원복을 확인한다.
- 문서(M0) 완료 전에는 코드·설정을 변경하지 않는다.
