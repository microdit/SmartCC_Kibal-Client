## 1. 배경

6700 회의실 영상 지연 이슈에서 원인은 단말 무선 링크의 영상 패킷 손실이었다. 문제는 해결됐지만, 사용자가 품질 상태를 **앱 안에서 즉시 확인·제어**할 수 없어 원인 판단에 OPS 로그 조회 명령이 필요했다.

이에 로그 전송 제어, 품질 지표 시각화, 수동 영상 품질 설정, 전체화면 실시간 진단을 하나의 흐름으로 기획했다.

## 3. 기능 정의

### 3.1 로그보내기
- 자동보내기: 즉시 1회 전송 후 5분 주기 분할 전송, 설정 저장.
- 즉시보내기: 현재 로그 1회성 전송. 자동과 동시 사용 가능.

### 3.2 품질 지표 보기
- OPS `/api/client-logs`의 `video summary`/`media summary` 파싱.
- 평균 fps/videoKB, vLost/freeze/pli 증가량, ICE 상태, 양호/주의/위험 판정.
- 표 + `CustomPaint` 그래프(외부 차트 패키지 없음).

### 3.3 영상 품질 수동 설정
- 320p/640p/720p/1080p/4K × 15/24/30/60fps 조합.
- 자동은 WebRTC에 위임, 수동은 `setParameters` + 트랙 교체 적용.

### 3.4 전체화면 실시간 진단
- 전송속도 진단 버튼으로 패널 on/off.
- 영상/음성/네트워크 실시간·60초 평균 표시.
