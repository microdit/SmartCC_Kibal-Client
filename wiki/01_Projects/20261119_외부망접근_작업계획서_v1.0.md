## 1. 현재 상태 및 확정 사실

- 토폴로지: **IPTime2 폐기**, IPTime1(공인 IP) + L2 스위치 단일 대역 `192.168.11.0/24`.
  - Mac Pro `192.168.11.5` (Asterisk/OPS), PRD NAS `nas2` `192.168.11.3`.
- DDNS `appletreeda.synology.me` 사용 중, **해당 도메인용 인증서는 Synology에 이미 발급됨**.
- 클라이언트는 `ws://` 평문 기본, Google STUN만 설정, TURN 미구성, 외부 실기검증 0건.
- 서버 `deploy/dev/.env` = `MEDIA_ADDRESS=192.168.11.5`, RTP `10000-10200`.
- PRD `deploy/prd/.env` = `MEDIA_ADDRESS=CHANGE_ME_PUBLIC_IP` (placeholder), RTP `10000-20000`.

## 3. 실행 순서 (임계 경로)

```
W1(포트) + W2(인증서) ──> W3(WSS 설정) ──> W5(재시작) ──> W7(실기)
                              └──> W4(공인 media_address) ──┘
W6(클라이언트 프로필) ──────────────────────────────────────┘
W7 완료 ──> W8(PRD/외부 프로필) ──> W9(TURN) ──> W10(문서·동기화)
```

- **원칙**: 실통화 중에는 컨테이너 재생성 금지(transport 변경은 reload 불가, 재시작 필요).
- W7 실패 시 OPS 클라이언트 로그(`scripts/ops_client_logs.sh`)와 Asterisk 로그를 타임스탬프로 교차 분석한다.

## 4. 수용 기준 (Definition of Done)

| 항목 | 기준 |
|------|------|
| TLS | `openssl s_client -connect appletreeda.synology.me:8089` 검증 성공, 인증서 호스트명 일치 |
| 시그널링 | `wss://appletreeda.synology.me:8089/ws`로 REGISTER 200 OK, 294초 갱신 유지 |
| 미디어 | SDP `c=`가 공인 IP, 양방향 RTP, `audioBytes>0`/`videoBytes>0`, ICE failed 0 |
| 통화 | 1:1 및 3자 ConfBridge 2분 이상 유지, 재INVITE/recvonly 회귀 없음 |
| 보안 | 8088/8091/5060 외부 미노출, `badCertificateCallback` 전면허용 WAN 프로필에서 제거 |
| 운영 | DDNS/IP·인증서 갱신 절차 문서화, OPS 로그 수집 정상 |

## 5. 리스크 및 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 공인 IP 동적 변경 → SDP `c=` 갱신 누락 | 외부 미디어 단절 | DDNS 해석 → `media_address` 반영 스크립트, 변경 시 재시작 |
| 인증서 만료/경로 오류 | WSS 연결 실패 | 갱신 자동화 + 만료 알림, 클라이언트 오류 메시지 |
| 대칭NAT/CGNAT 단말 | STUN 실패 | TURN relay(W9), `turns:` 443 |
| UDP 전량 차단 | RTP 단절 | TURN over TCP/TLS, 화질 저하 감수 |
| OPS 8091 노출 | 보안 사고 | 포트 미개방, VPN/SG 격리 |
| PRD placeholder 미해소 | PRD 배포 불가 | W8에서 실 공인 IP/도메인 확정 |
| DDNS 장애 | 접속 불가 | 마지막 IP 캐시 + 수동 서버 설정 override |
