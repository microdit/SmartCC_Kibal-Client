# 클라이언트 로그 자동 수집(OPS 콘솔) 작업계획서

| 항목 | 값 |
|------|-----|
| **작성일** | 2026-11-11 |
| **버전** | v1.0 |
| **대상** | `SmartCC_Kibal-Client`(macOS 클라이언트) + `SmartCC_Kibal`(OPS 서버) |
| **목적** | 클라이언트 로그 수동 수집 → 자동 서버 저장 → OPS 콘솔/에이전트가 실시간 조회·분석 |
| **상태** | 완료 (v0.0.12 / ops API+웹 배포·검증) |

---

## 1. 배경·목표

- 현재 각 단말의 `app.log`를 수동으로 복사해 분석하므로 느리고 누락이 잦다.
- 클라이언트가 로그를 **서버(OPS)로 자동 배출**하고, OPS 콘솔 웹에서 내선별로 조회하게 한다.
- 개발 중인 에이전트가 **실시간 로그를 바로 열람**해 피드백 루프를 단축한다.

## 2. 아키텍처

```
macOS 클라이언트(1101/1102/1103)
  AppLogger.instance.stream (실시간 로그 스트림)
        │
        ▼
  RemoteLogForwarder (배치 버퍼, 2초 주기 flush)
        │  POST /api/client-logs  (X-Client-Key: OPS_CLIENT_KEY)
        ▼
  OPS 콘솔 서버 (kibal-dev-ops / kibal-prd-ops, Flask, port 8091)
        │  ClientLogStore.write → /var/lib/kibal-ops/client-logs/<extension>.log
        ▼
  GET /api/client-logs?extension=1102&tail=200&q=...  (cli key or 로그인 세션)
        ├─ OPS 웹 콘솔 (React) — "클라이언트 로그" 탭
        └─ 에이전트 (curl / docker exec cat) — 실시간 분석
```

## 3. 범위

| 번호 | 작업 | 저장소 | 비고 |
|------|------|--------|------|
| P0-1 | OPS API: 클라이언트 로그 수신·조회 엔드포인트 | server | `client_logs.py`, routes, config |
| P0-2 | 클라이언트: 원격 로그 자동 배출(RemoteLogForwarder) | client | `dart:io`, 무의존 |
| P0-3 | 인증: 공유 키 `OPS_CLIENT_KEY`(X-Client-Key) + ops.env | server | 로그인 불필요(클라이언트용) |
| P1-1 | OPS 웹 콘솔: 클라이언트 로그 조회 UI | server/web | 내선 선택 + tail + 필터 + 자동갱신 |
| P1-2 | 에이전트 조회 도구(스크립트) | client | `scripts/ops_client_logs.sh` curl 래퍼 |
| P2-1 | 보안: PRD 키 교체, 로그 레드액션/보존정책 | server | OPS_READ_ONLY 등 연계 |
| P2-2 | 로그 보존·로테이션(크기/라인) | server | 이미 크기 로테이션 구현 |

## 4. 설계 세부

### 4.1 서버(`smartcc_kibal`)

- `server/ops/api/app/client_logs.py`
  - `ClientLogStore(root, max_bytes, keep_lines)` — 내선별 파일 append + 크기 초과 시 tail 로테이션
  - `append(extension, lines)`, `tail(extension, tail)`, `list_clients()`
- `routes.py`
  - `POST /api/client-logs` — `_client_authorized()`(X-Client-Key 또는 로그인), JSON `{extension, lines[]}` 수신
  - `GET /api/client-logs?extension=&tail=&q=` — 클라이언트 목록 + tail 라인(필터)
- `config.py` — `OPS_CLIENT_LOG_DIR/MAX_BYTES/KEEP_LINES/TAIL_MAX`
- `__init__.py` — `app.extensions["client_logs"]` 등록
- `deploy/{dev,prd}/ops.env` — `OPS_CLIENT_KEY` 추가

### 4.2 클라이언트(`SmartCC_Kibal-Client/macos-client`)

- `lib/src/utils/remote_log_forwarder.dart`
  - `AppLogger.instance.stream` 구독 → 버퍼(최대 500) → 2초 주기 flush
  - `dart:io HttpClient` POST, 4s/5s 타임아웃, 실패는 무시(로컬 로깅에 무영향)
- `constants.dart` — `opsPort=8091`, `opsClientKey`, `opsLogUrl(domain)`
- `main.dart` — 앱 시작 시 포워더 start(기본 도메인/unknown)
- `sip_client.dart` — 등록 성공 시 도메인/내선 반영(라우팅·식별)
