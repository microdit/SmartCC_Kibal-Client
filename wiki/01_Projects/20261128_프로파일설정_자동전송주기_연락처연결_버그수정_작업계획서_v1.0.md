## 1. 배경

사용자 실기 보고:
1. 외부망 프로파일 값이 `8089/8091/5060`으로 표시됨.
2. 연결설정 저장/연결 테스트 후 값이 유지되지 않는 듯함. 자동전송 주기 1분 선택 후 재진입 시 5분으로 복귀.
3. 주소록 연락처 번호 선택 후 "연결" 버튼 오류.

## 2. 코드 근거

- `macos-client/lib/src/utils/server_config.dart:45-56` external 기본값이 DEV 외부망(`appletreeda.synology.me:8089/wss:8089/8091`)으로 고정.
- `macos-client/lib/src/ui/settings/settings_screen.dart:159-170` `_applyLogUrl()`이 `RemoteLogSettings` 재생성 시 `autoSendMinutes` 미전달.
- `macos-client/lib/src/ui/settings/settings_screen.dart:171-279` 프로파일 전환 시 manifest refresh + resolved config 적용.
- `macos-client/lib/src/ui/home/address_book_screen.dart:414-457` 연락처 "연결"이 선택 연락처 extension으로 SIP 등록 시도.
