**날짜**: 2026-11-12
**버전**: v1.0
**대상**: macOS Client v0.0.19
**관련**: 화면설계 `wiki/02_Design/회의화면_화면설계서_20261112.md` v1.2, 완료보고서(예정) `wiki/06_Reports/20261112_영상전체화면_완료보고서_v1.0.md`

## 1. 배경
v0.0.18 실기 확인(3자 6000): 참가자 카드·이름 배지·"카메라 없음" 정상(1101 김민석, 1102 이재명, 1103 홍길동1103).
요청: 중앙(큰 화면) 영상을 **완전 전체 화면**으로 보고 회의를 계속할 수 있어야 함. 1:1·다자간 동일 컨셉.

## 2. 요구사항
| # | 요구 |
|---|------|
| R1 | 큰 화면 영상 **더블클릭 → 전체 화면**(macOS 창 전체화면 + 앱 바·카드·하단 바 숨김, 영상만) |
| R2 | 전체 화면에서 **다시 더블클릭 → 이전 화면 크기/레이아웃 복귀** |
| R3 | 전체 화면 중 통화 유지(음성·영상 끊김 없음), 이름 배지 유지 |
| R4 | `Esc`로도 복귀, 전체 화면 중 마우스 이동 시 최소 컨트롤(마이크·종료) 오버레이 3초 표시 |
| R5 | 1:1 통화 화면(`call_screen.dart`)도 원격 영상 더블클릭 동일 동작 |
| R6 | 통화 종료 시 자동으로 전체 화면 해제 |

## 3. 설계
- 창 전체화면: macOS `NSWindow.toggleFullScreen` — `MethodChannel('kibal/window')`(`MainFlutterWindow.swift`), 실패 시 앱 내부 확장만
- 앱 내부: `_fullscreen` 상태 → Scaffold appBar/bottom/카드 숨김, 큰 영상 `Positioned.fill`
- 공통 위젯 `FullscreenVideoController`(utils) — enter/exit/toggle, 상태 notifier
- 로그: `UI VIDEO action=fullscreenEnter|fullscreenExit params=screen=conference|call label=..`
