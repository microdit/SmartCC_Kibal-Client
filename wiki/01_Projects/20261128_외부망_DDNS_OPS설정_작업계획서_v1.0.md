# 외부망(DDNS) OPS 설정/문서화 작업계획서

- 문서 버전: v1.0
- 작성일: 2026-11-28
- 작성자: opencode
- 브랜치: Server `feature/external-network-wss`, Client `test/client-v0.0.64-recovery`
- 상태: 진행 중

## 1. 사용자 지시

- 외부망일 때 무엇이 어떻게 설정되어야 하는지 wiki 문서 작성.
- 설계/기획/테스트/확인된 것 기록, wiki 로그 기록, 이력 남김.
- 양쪽 wiki 모두 기록, 벡터 DB 기록, 커밋/푸시/동기화.
- 구현 진행. 작업계획서 설명 남기고 진행.

## 2. 결정 사항

- **서버 자동 변경 금지**: 클라이언트 외부망 접속 감지로 서버 설정을 자동 토글하지 않는다.
- **고정 오픈 권장**: DDNS/포트포워딩/TURN/Asterisk external/WS(S) 포트를 상시 운영.
- **유동 설정은 OPS에서 명시 적용**: DEV/TEST 별도 외부망 설정 페이지, active call 검사, 감사로그, 검증/롤백.

## 3. 작업 범위

| ID | 작업 | 대상 | 상태 |

## 4. 구현 상세

### Server OPS
- API: `GET/PUT /api/settings/external-network` (또는 기존 settings 확장) — DDNS, 공개 포트, TURN URL, 인증서 상태, 점검 결과.
- 점검: DNS resolve, TCP/UDP 포트 리슨, OPS health, coturn/Asterisk config 스냅샷, active call 차단.
- UI: Settings 또는 신규 External Network 페이지. DEV/TEST 라벨, 적용 전 경고, 감사로그.

### Client
- 자동전송 주기 보존 버그 수정.
- 외부망(DDNS) 프로파일 의미 명확화, TEST/DEV 후보 오염 방지.
- 연락처 연결 버튼: 통화 중/인증 내선 불일치 차단, 안내 메시지.

## 5. 검증

- `python3 -m py_compile server/ops/api/app/*.py`
- `npm -C server/ops/web run build`
- `flutter analyze` 수정 파일
- 문서 링크/파일 존재 확인
