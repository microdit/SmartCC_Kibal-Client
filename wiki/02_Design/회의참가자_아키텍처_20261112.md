## 1. 구성

```
macOS Client (회의 화면)
  ├─ SIP/WebRTC ──────────── Asterisk ConfBridge 6000 (SFU)
  │    원격 영상 트랙(m-line 순)      softbridge_dest_<채널>_N 스트림
  └─ HTTP 5초 폴링 ─────────  OPS API (Flask)
       GET /api/conference/6000/participants?extension=1101
                                 └─ docker exec asterisk -rx
                                     confbridge list 6000
                                     core show channel PJSIP/<채널>
```

## 2. 서버 API

`GET /api/conference/<room>/participants?extension=<요청 내선>` — 헤더 `X-Client-Key`

```json
{
  "ok": true,
  "data": {
    "room": "6000",
    "count": 3,
    "participants": [
      {"channel": "PJSIP/1101-00000007", "extension": "1101", "caller_name": "Kibal Web 1101", "has_video": false, "self": true},
      {"channel": "PJSIP/1102-00000004", "extension": "1102", "caller_name": "Kibal Web 1102", "has_video": true, "self": false}
    ],
    "video_order": ["PJSIP/1102-00000004", "PJSIP/1102-00000005"]
  }
}
```

| 필드 | 산출 |
|------|------|
| `participants` | `confbridge list <room>` 각 행 Channel/CallerID |
| `has_video` | 해당 채널 `-- Streams --`에서 자기 영상 스트림(`softbridge_dest_` 아닌 video)의 State가 `sendrecv` 또는 `recvonly`(서버가 수신) |
| `self` | 채널 내선 == 요청 extension (중복 접속 시 모두 true) |
| `video_order` | 요청자 채널(가장 최근)의 `softbridge_dest_<채널>_N` 스트림 순서 = 클라이언트 원격 영상 m-line 순서 |

보안: room `^\d{3,6}$`, 채널 `^PJSIP/[0-9A-Za-z_.-]+$`만 CLI 인자로 사용.

## 2.1 표시 이름

- 앱 로그인 시 `POST /api/client/profile {extension, display_name, host}` (X-Client-Key) → OPS `client-logs/profiles.json`
- 참가자 API가 각 참가자에 `display_name` 추가: 저장된 표시 이름, **없으면 내선 번호**
- Asterisk endpoint `callerid`(Kibal 1101 등)는 서버 고정값이라 사용하지 않음

## 3. 클라이언트 매핑

1. 카드 목록 = 참가자 중 `self=false` 전원 + 내 카드
2. 영상 매핑: `video_order`에서 `has_video=true`인 채널만 남긴 순서 ↔ `MediaProvider.remoteStreams` 순서
3. 매핑되는 스트림 없으면 카드 상태 = "영상 없음"(has_video=false) 또는 "영상 수신 준비중"(has_video=true)
4. 라벨 = `표시이름 (내선)`(표시 이름 없으면 내선), 같은 내선 2개 이상이면 `#1`, `#2` 접미. 내 카드 = `나 · 표시이름 (내선)`
5. API 실패/미응답 → 기존 방식(원격 트랙마다 `원격 N` 카드)

## 4. 판정 근거 (2026-11-12 실측)

| 채널 | 자기 video 스트림 State | 의미 |
|------|------------------------|------|
| 1101-00000007 | `sendonly` | 서버→1101만, 1101 송신 없음 → 영상 없음 |
| 1102-0000000x | (카메라 송신) | 영상 있음 |
