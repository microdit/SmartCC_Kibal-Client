# A10 연동 클라이언트 설계서 (화면·데이터·코덱)

**날짜**: 2026-11-12 · **버전**: v1.0 · **화면 ID**: UI-MAC-DEV-01, UI-MAC-CONF-02
**관련**: 서버 HLD-A10-001, LLD-A10-001, ADR-003 / 클라이언트 ADR-007

## 1. 미디어 장치 선택

### 1.1 화면 (UI-MAC-DEV-01, 미디어 테스트 확장)
```
┌ 장치 설정 ─────────────────────────────┐
│ 카메라   [Yealink A10 Camera ▼] ⭐추천   │  미리보기
│ 마이크   [Yealink A10 Audio  ▼] ▮▮▮▯ -32dB │
│ 스피커   [Yealink A10 Audio  ▼] [테스트음] │
│                         [기본값] [저장]   │
└──────────────────────────────────────────┘
```
| 요소 | 동작 |
|------|------|
| 드롭다운 | `enumerateDevices()` videoinput/audioinput/audiooutput |
| 추천 배지 | label에 `Yealink`/`A10`/`MeetingBar` 포함 |
| 저장 | `media-devices.json` 기록, 다음 통화부터 적용(통화 중이면 다음 통화) |
| 장치 분리 | 저장 장치 없으면 기본 장치 + 스낵바 "A10 카메라 없음 — 기본 장치 사용" |

### 1.2 데이터 `<logs>/media-devices.json`
```json
{"camera": {"id": "...", "label": "Yealink A10 Camera"},
 "mic": {"id": "...", "label": "Yealink A10 Audio"},
 "speaker": {"id": "...", "label": "Yealink A10 Audio"},
 "updatedAt": "2026-11-12T..."}
```
매칭: id 우선, 실패 시 label 일치(USB 재연결 시 id 변경 대비).

## 2. 회의실별 코덱 정책 (ADR-007)
| 대상 | 비디오 우선순위 | 방법 |
|------|----------------|------|
| 6000~6099 | VP8 → H.264 (기존) | 변경 없음 |
| 6100~6199 | **H.264 only** | offer SDP `m=video`에서 H.264 PT만 남김(+rtx), `profile-level-id=42e01f` 우선 |
| 1:1 상대가 SIP 단말(12xx) | H.264 → VP8 | m=video PT 재정렬 |
구현: `sdp_codec.dart` `preferVideoCodec(sdp, 'H264', exclusive)` — sip_ua `onSdp`/`sdpTransform` 훅에서 로컬 offer/answer 가공. 로그 `SIP codec policy target=.. video=..`.

## 3. 6100 회의 화면 (UI-MAC-CONF-02)
```
┌ 회의실 6100 · 참가자 3명 · 발언자 화면 ──── [⟳] [종료] ┐
│                                                        │
│        현재 발언자 영상 (follow_talker 단일 스트림)        │
│  👤 A10 회의실 (1201)                                    │
├────────────────────────────────────────────────────────┤
│ 참가자: A10 회의실(1201) 🎤 · 이재명(1102) · 나(1101)     │  목록(영상 없음)
└────────────────────────────────────────────────────────┘
```
- 원격 영상 1개만 존재 → 큰 화면 고정, 라벨은 "발언자 영상"(서버가 발언자 식별 미제공; 참가자 목록만 표시)
- 더블클릭 전체 화면, 영상 동기화 버튼 동일 적용
