## 2. 카드 상태

| 상태 | 조건 | 표시 |
|------|------|------|
| 영상 | 매핑된 원격 스트림 있음 | 실시간 썸네일 + 라벨 |
| 영상 없음 | `has_video=false` | 회색 배경, `Icons.mic` + "영상 없음" + 라벨 |
| 영상 수신 준비중 | `has_video=true`, 스트림 미매핑 | `Icons.videocam_off_outlined` + "영상 수신 준비중" |
| 내 카드 | 로컬 | 카메라 있으면 미러 영상, 없으면 "카메라 없음", 라벨 "나 (1101)" |
| 선택 | 사용자가 탭 | 파란 테두리 3px, 큰 화면에 표시 |

## 3. 큰 화면

- 선택 카드를 크게 표시. "영상 없음" 참가자 선택 시 큰 화면에 큰 마이크 아이콘 + "1101 · 영상 없음(음성 참여)".
- 초기 선택: 영상 있는 첫 참가자, 없으면 첫 참가자.

## 4. 동작

| 이벤트 | 동작 |
|--------|------|
| 회의 입장 | 참가자 폴링 시작(즉시 1회 + 5초 주기) |
| 회의 종료/화면 이탈 | 폴링 중지 |
| 참가자 변화 | 카드 갱신, 로그 `CONFERENCE participants n=.. video=..` |
| 카드 탭 | 선택, 로그 `participantSelected label=..` |
| API 실패 | 기존 트랙 기준 카드(`원격 N`) |

## 4.1 이름 표기 규칙 (큰 화면·작은 카드 공통)

| 위치 | 표기 | 스타일 |
|------|------|--------|
| 원격 참가자 | `표시이름 (내선)`, 표시 이름 없으면 `내선` | 좌상단 배지(사람 아이콘), 큰 화면 20pt·카드 12pt, 반투명 검정 배경 |
| 내 카드/PIP | `나 · 표시이름 (내선)` | 동일 |
| OPS 미응답 | `참가자 N` | 동일 |

## 5. AppBar

`회의실 6000 · 참가자 N명` (N = 서버 참가자 수, API 실패 시 생략)
