# 외부망(DDNS) 접속 구성 설계서

- 문서 버전: v1.0
- 작성일: 2026-11-28
- 작성자: opencode
- 상태: 설계 확정(구현 진행)

## 1. 목표

DDNS(`appletreeda.synology.me`)를 통해 외부망 클라이언트가 DEV/TEST/PRD 환경에 접속할 수 있도록, 서버 설정을 **고정/명시적 운영** 기준으로 정의한다. 클라이언트 접속 감지에 따른 서버 자동 토글은 금지한다.

## 2. 원칙

1. **고정 오픈**: 외부 접속에 필요한 포트/인증/TLS/DDNS는 상시 유지.
2. **자동 변경 금지**: 클라이언트가 외부망으로 붙었다고 Asterisk/OPS/coturn 설정을 런타임 자동 변경하지 않음.
3. **환경 분리**: DEV/TEST/PRD/EXTERNAL은 포트·DB·컨테이너·로그·OPS·Asterisk·DMG 완전 분리.
4. **감사 가능성**: 외부망 설정 변경은 OPS UI/API에서 수행하고 감사로그에 남김.
5. **active call 안전**: 파괴적 적용/재시작은 active call > 0이면 BLOCKED.

## 3. 환경별 외부망 엔드포인트(목표)

| 환경 | OPS | SIP/WS | WSS | TURN/TURNS | RTP(UDP) | 비고 |
|---|---:|---:|---:|---|---:|---|
| DEV | 8091/tcp | 5060/udp, 8088/tcp | 8089/tcp | 3478/tcp,udp, 5349/tcp | 10000-10200/udp | 기존 기본 |
| TEST | 18091/tcp | 15060/udp, 18088/tcp | 18089/tcp | 3478/tcp,udp, 5349/tcp(공유 가능) | 11000-11100/udp | TEST 전용 |
| PRD | 별도 확정 | 별도 확정 | 별도 확정 | 별도 확정 | 별도 확정 | PRD는 완전 신규 설치 |
| EXTERNAL | 별도 확정 | 별도 확정 | 별도 확정 | 별도 확정 | 별도 확정 | PRD 이식성/외부망 점검 |

> DDNS는 공통(`appletreeda.synology.me`) 사용 가능하나, 환경별 포트/인증/데이터는 분리한다.

## 4. 구성 요소별 필수 설정

### 4.1 DNS/라우터
- DDNS A/AAAA 또는 CNAME가 공인 IP를 가리킴.
- ipTIME 포트포워딩: 위 표의 환경별 포트 → 해당 호스트(`192.168.11.5` 등).
- UDP/TCP 구분 정확히 설정(TURN 3478 udp/tcp, TURNS 5349 tcp).

### 4.2 coturn
- `use-auth-secret`, `static-auth-secret`, `realm=appletreeda.synology.me`.
- `external-ip=공인IP` 또는 적절한 NAT 설정.
- `no-multicast-peers` 유지.
- 외부 relay 허용 시 `allowed-peer-ip` 과도 제한 금지(단, 보안 정책 검토). 인증 기반 허용.
- TLS 인증서(`cert/pkey`)는 TURNS 사용 시 유효해야 함.

### 4.3 Asterisk
- `external_media_address`, `external_signaling_address` = 공인IP/DDNS 해석 대상.
- `local_net`에 내부망/도커망 포함.
- NAT: `rtp_symmetric=yes`, `force_rport=yes`, `rewrite_contact=yes`.
- ICE: `icesupport=yes`, STUN은 환경 정책에 따라 명시(6700 이슈 재발 시 별도 검증).
- WS/WSS transport 분리, 인증서 경로 유효.

### 4.4 OPS
- `/api/client/config`가 요청 호스트/프로파일에 맞는 endpoints 반환.
- profile manifest에 DEV/TEST/PRD/EXTERNAL/DDNS 후보 포함, 환경 오염 금지.
- 외부망 설정 페이지에서 값 조회/저장/검증/적용 이력 제공.
- active call 확인 후 적용. 실패 시 롤백/경고.

### 4.5 Client
- 프로파일별 독립 상태(`env+extension`) 유지.
- DDNS 사용 시 내부망/LAN 자동전환 예외 처리(명시 선택 우선).
- 연결 테스트는 선택 프로파일 기준으로 수행하고, 다른 환경 후보 오염 금지.

## 5. 보안

- TURN은 secret 기반 임시 자격 사용, static shared secret 노출 금지.
- OPS 클라이언트 키/내선 바인딩 유지.
- 외부망 설정 변경 API는 인증/권한 필요, 감사로그 기록.
- 공개 포트는 필요한 범위만 개방, TLS 인증서 만료 감시.

## 6. 테스트/검수

1. DNS: `appletreeda.synology.me` 해석 확인.
2. 포트: 외부에서 18091/18088/18089/15060/3478/5349 연결 확인.
3. OPS: `/api/client/config`가 외부 요청에 맞는 ws/ops/turn 반환.
4. SIP 등록: 외부망 클라이언트 REGISTER 성공.
5. 통화: 1:1, 6000/6100, 6700 영상/오디오/RTP timeout 확인.
6. 로그: client log, Asterisk, coturn, OPS 감사로그에 환경 식별자 포함.

## 7. 구현 항목

- Server: OPS 외부망 설정 조회/저장/검증 API, 감사로그, UI 페이지.
- Client: 외부망 프로파일/자동전송 주기/연락처 연결 버그 수정(진행 중).
- Docs/Wiki: 본 설계서, 작업계획서, 테스트 체크리스트, 로그/이력.
