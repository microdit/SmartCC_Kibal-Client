# A10 100인 영상회의 설계서

| 항목 | 내용 |
|---|---|
| 문서 ID | DES-20261123-CONF100-001 |
| 버전/작성일 | v1.0, 2026-11-23 |

## 1. 아키텍처
- ConfBridge `kibal_bridge_ft`: follow_talker, enable_events=yes.
- max_members=100 (기존 10).
- video_mode=follow_talker: 발화자 1명 영상만 전달 → 대역폭 절약.
- 오디오: 모든 참가자 믹싱.
- 코덱: H.264 공통 (A10 HP, 클라이언트 CBP는 회의실에서 ConfBridge가 흡수).

## 2. 대역폭
- 영상 1스트림 (발화자) + 오디오 N스트림.
- 100명 시 오디오 믹싱 부하 주의.

## 3. 제약
- Asterisk 트랜스코딩 없음 → 공통 코덱 필수.
- 1:1은 simple_bridge (프로파일 정렬 필요).
