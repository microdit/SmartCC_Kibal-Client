# 회의 데이터 설계서 (참가자·표시 이름·영상 동기화)

**날짜**: 2026-11-12
**버전**: v1.0
**저장소**: OPS 컨테이너 볼륨 `/var/lib/kibal-ops/client-logs/`

## 1. 파일
| 파일 | 내용 | 갱신 |
|------|------|------|
| `profiles.json` | `{ "<내선>": {display_name, host, updated_at} }` | 앱 로그인 시 `POST /api/client/profile` |
| `conference_sync.json` | `{ "<room>": {seq, by, at} }` | `POST /api/conference/<room>/sync` |
| `<내선>.log`, `<내선>.meta.json` | 클라이언트 로그(기존) | 업로더 |

## 2. API 데이터
### GET /api/conference/<room>/participants?extension=
| 필드 | 타입 | 설명 |
|------|------|------|
| room | str | 회의실 |
| count | int | 참가자 수 |
| participants[].channel | str | `PJSIP/1102-00000004` |
| participants[].extension | str | 내선 |
| participants[].display_name | str | 표시 이름, 없으면 내선 |
| participants[].has_video | bool | 단말 → 서버 영상 송신 여부 |
| participants[].self | bool | 요청 내선과 동일 |
| video_order | [str] | 요청자 원격 영상 m-line 순서(채널) |
| sync_seq / sync_by | int / str | 영상 동기화 요청 순번 / 요청 내선 |

### POST /api/client/profile `{extension, display_name, host}`
### POST /api/conference/<room>/sync `{extension}` → `{room, seq, by, at}`

모두 `X-Client-Key` 필요. 입력 검증: 내선 숫자, room 3~6자리 숫자, 채널 `^PJSIP/[0-9A-Za-z_.-]+$`.

## 3. 클라이언트 상태
| 객체 | 필드 |
|------|------|
| `ConferenceSnapshot` | participants, videoOrder, syncSeq, syncBy |
| `ConferenceParticipantService` | _lastMembers(채널 집합), _lastSyncSeq → 변화 시 `onResyncNeeded(join|leave|remote:<ext>)` |
| 로그 | `CONFERENCE participants ...`, `VIDEO resync reason=... localKick=... remoteTiles=...`, `UI CONFERENCE videoSyncAll`, `UI VIDEO fullscreenEnter/Exit` |
