## 1. 현재 흐름과 문제 지점

```
A10(1201) --INVITE--> Asterisk(192.168.11.5) --INVITE--> macOS(1102)
   |                        |                              |
   |<--- 200/ACK -----------|<--- 200(수락) ---------------|
   |                        |                              |
   |  영상 품질 파라미터 적용 fps=60 (1102)                  |
   |  TURN 370401 Unauthorized (Asterisk RTP 로그 반복)     |
   |  qualify OPTIONS 무응답 → 1201 Unavail 표시             |
   |                        |                              |
   |<---------- BYE (수락 1.8초 뒤, A10 발신) --------------|
```

- 6100 회의실(follow_talker, 30fps)은 30분+ 유지 → 문제는 1:1 협상/미디어 파라미터에 한정.

## 2. 변경 설계

### 2.1 fps 상한 (조치 1)
- **위치**: `macos-client/lib/src/sip/sip_client.dart` `applyVideoQuality()` 및 수신 경로
- **설계**: SIP 단말(1201 계열)과의 1:1에서 `VideoQualitySettings.frameRate` 상한을 30으로 제한. auto 모드도 30 사용.
- **근거**: A10 코덱 H.264 HP/H.264, 실측 최대 30fps. 1102 로그 `fps=60` 적용 2회가 BYE 직전에 발생.
- **영향**: WebRTC↔WebRTC 1:1은 기존 auto 유지(동일 로직 내 target 기반 분기).

### 2.2 LAN TURN 비활성화 (조치 2)
- **위치**: `sip_client.dart` `_buildIceServers(config)`, OPS `/api/client/config`의 `turn` 필드
- **설계**:
  - 클라이언트: `onLan == true && profile이 내부 대역(192.168.11.x)`이면 TURN URL을 iceServers에서 제외, host/srflx만 사용.
  - OPS: 외부망 요청(`external=true`)일 때만 TURN 자격증명 노출, 내부 요청은 `turn: null` 반환(또는 클라이언트가 무시).
- **근거**: Asterisk `res_rtp_asterisk`가 반복 `PJ ICE Rx error 370401 'Unauthorized'` — LAN 내부에서 TURN Allocation 시 인증 실패. 회의는 host candidate로 성공하나 1:1에서 불안정 요인.
- **보안**: TURN 자격증명은 외부망에만 노출(기존 원칙 유지).

### 2.3 qualify 비활성화 (조치 3)
- **위치**: `SmartCC_Kibal/server/asterisk/config/pjsip.conf.template` `[1201]` aor
- **설계**: `qualify_frequency=30` 제거(또는 0). A10은 SIP REGISTER는 유지하나 OPTIONS 미응답 → Unavail 오표시 방지.
- **운영**: 런타임 pjsip.conf에도 반영, 재생성 시 템플릿으로 자동 적용. 단, 재생성은 활성 통화 가드로 창구 필요.

## 3. 데이터/연동 흐름 (변경 후 목표)

```
OPS /api/client/config ──(LAN)──▶ turn: null ──▶ 1102 iceServers: [stun/host]
A10 → 1102 1:1 ── fps 30 ──▶ ConfBridge/simple_bridge ──▶ 60초+ 유지
1201 aor: qualify off ──▶ contact Avail 유지
```

## 4. 검증 설계
- A10 웹 Dial → 1102 Video Call → 1102 수락
- 기대 로그:
  - `PJSIP/1102 answered PJSIP/1201`, `simple_bridge join` 유지
  - 1102 `SIP video summary ... in=...fps`, videoTracks=1/1 60초 이상
  - Asterisk `370401` 없음, `pjsip show contacts` 1201 Avail
