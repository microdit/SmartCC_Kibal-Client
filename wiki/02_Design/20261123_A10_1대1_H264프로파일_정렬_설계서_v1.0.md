# A10 1:1 H.264 프로파일 정렬 설계서

| 항목 | 내용 |
|---|---|
| 문서 ID | DES-20261123-A10-1TO1-P2-001 |
| 버전/작성일 | v1.0, 2026-11-23 |

## 1. 문제
- 1:1 simple_bridge는 양단 코덱/프로파일이 일치해야 미디어 중계.
- A10: H.264 HP(42002a) + H.264. 클라이언트: Constrained Baseline(42e01f).
- 불일치 시 영상 트랙이 생성되나 RTP가 흐르지 않고 A10이 BYE.

## 2. 설계
- 클라이언트 SDP offer/answer에서 H.264 프로파일을 A10 HP(42002a) 우선으로 정렬.
- A10 측 H.264 HP만 활성화(HP 비활성 옵션 존재 시) 또는 Baseline으로 고정.
- Asterisk endpoint `allow`에 h264 유지(트랜스코딩 불가 전제).

## 3. 검증
- 1102→1201 / 1201→1102 60초+ 유지, videoBytes>0, videoTracks=1/1.
