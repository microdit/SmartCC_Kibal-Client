## 1. 목적/범위
v0.0.26~v0.0.28에 반영된 **빠른연결 Ops 동적 로드(로그인/다이얼러)** 및 **다이얼러 통화 버튼 활성화/발신 동작** 변경 사항을 검수하기 위한 절차서이다.

- **포함 변경**:
  - v0.0.26: 다이얼러 빠른연결을 Ops 연락처/회의실(`GET /api/client/contacts`, `GET /api/client/conferences`) 기반 동적 로드·새로고침 (미도달 시 폴백).
  - v0.0.27: 로그인 빠른연결 Ops 연락처 동적 로드·새로고침(서버설정 갱신 후 재조회), DEV 계정만 비밀번호 자동입력; 다이얼러 통화 버튼 활성 조건을 번호 입력 기준으로 조정.
  - v0.0.28: 다이얼러 대상번호 변경 시 통화 버튼 **즉시** 활성/비활성(컨트롤러 리스너) — 다이얼패드/빠른연결/백스페이스/지우기 등 프로그램적 변경 포함.
  - 기존 포함: W2 0-dim 렌더러 패치(네이티브 크래시 완화) 반영 빌드 기반.
- **범위 외(별도)**: W3 실기(H5/F1/H6·P0 크래시 재현), W4(AMI 영상소스)/W5 영속 적용 등.

## 2. 사전 조건
| 항목 | 내용 |
|------|------|
| Ops 서버 | 도달 가능 (기본 `http://<SIP도메인>:8091`). 로그인 ‘서버 설정 갱신’으로 SIP/WS/OPS 주소 반영 |
| 클라이언트 인증 | `X-Client-Key`(앱 `AppConstants.opsClientKey`, 기본 DEV `dev-kibal-clients-2026`)가 서버 `OPS_CLIENT_KEY`와 **일치**해야 Ops 목록 조회 성공 |
| 폴백 동작 | 키 불일치/미도달 시 로그인: 1101~1103, 다이얼러: 1101~1103·6000,6100 표시(크래시/무한 로딩 없어야 함) |
| SIP/Asterisk | 등록 가능한 계정·서버 정상. 1:1 발신 검증 시 상대 단말 등록 필요 |
| 회의실 | Ops/서버에 등록·노출된 번호 사용(회의실 번호 6xxx → 회의 화면 흐름) |
| 빌드 확인 | 설치 앱이 v0.0.28+28이며 DMG/app bin SHA-256 일치 확인 권장 |

## 5. 결과 기록 양식
- **환경**: 테스터, 단말/OS, 앱 버전 `v0.0.28+28`(DMG/app SHA-256 확인 여부), 서버(Ops/SIP) 주소, `OPS_CLIENT_KEY` 일치 여부, 상대 단말/회의실 정보.

- **증빙(실패/이슈 시)**: 재현 단계, 시각(KST), 화면 캡처, 클라이언트 로그, 서버 관측 필요 시 Asterisk/OPS 로그(UTC) 병기.
- **비고**: 폴백 표시 여부(T1/T3), 자동입력 적용 계정(T2), 발신 경로/화면 전환(T5/T6).

## 6. 알려진 제약/참고
- 빠른연결 목록은 Ops 도달 + `OPS_CLIENT_KEY` 일치에 의존(불일치/미도달 시 폴백). 비밀번호 자동입력은 DEV 지정 계정(`devQuickAccounts`)에 한함.
- W3 실기(H5/F1/H6·P0 크래시 재현)·W4(AMI)/W5 영속 적용은 본 절차 범위 외(환경/승인/통화창구 제약 가능).
