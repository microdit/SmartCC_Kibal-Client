## 📱 1. 소개

**Kibal Mobile**은 Asterisk 기반 SIP 영상통화 시스템인 **SmartCC Kibal**의 공식 Mobile 클라이언트입니다.

이 가이드는 Kibal Mobile의 설치, 설정, 사용 방법에 대해 안내합니다.

### 1.1 특징

- ✅ **SIP 등록**: Asterisk 서버에 SIP 계정 등록
- ✅ **1:1 영상통화**: Mobile ↔ Mobile 또는 Mobile ↔ Web 영상통화
- ✅ **WebRTC 지원**: 고품질 영상/오디오 전송
- ✅ **다양한 프로토콜**: UDP, TCP, WebSocket, WSS 지원
- ✅ **플랫폼 지원**: iOS와 Android 지원

## 📥 2. 설치

### 2.1 iOS 설치

**사전 요구사항:**
- iOS 15.0 이상
- iPhone 또는 iPad

**설치 방법:**
1. App Store에서 "Kibal Mobile" 검색
2. "다운로드" 또는 " obtained" 클릭
3. 설치 완료 후 앱 실행

** 혹은 **

1. Xcode에서 빌드 (개발자용)
   ```bash
   cd /Users/microdit/Downloads/dev/SmartCC_Kibal-Client/mobile
   flutter build ios
   ```
2. Xcode에서 iOS 시뮬레이터 또는 실기기에서 실행

### 2.2 Android 설치

**사전 요구사항:**
- Android 10.0 이상
- 카메라 및 마이크 권한

**설치 방법:**
1. Google Play Store에서 "Kibal Mobile" 검색
2. "설치" 클릭
3. 설치 완료 후 앱 실행

** 혹은 **

1. Android Studio에서 빌드 (개발자용)
   ```bash
   cd /Users/microdit/Downloads/dev/SmartCC_Kibal-Client/mobile
   flutter build apk
   ```
2. 생성된 APK 파일을 Android 디바이스에 설치

## ⚙️ 3. 초기 설정

### 3.1 앱 첫 실행

1. **앱을 실행**합니다.
2. **환영 메시지**가 표시됩니다. "시작하기" 버튼을 누릅니다.

### 3.2 SIP 계정 설정

#### 기본 화면

```
┌─────────────────────────────────┐
│  Kibal Mobile                    │
│  SIP 영상통화 클라이언트         │
│                                 │
│  ┌─────────────────────────┐   │
│  │ 📞 SIP 설정                │   │
│  │                            │   │
│  │ 내선 번호: [    1101    ] │   │
│  │ 비밀번호: [********]      │   │
│  │ 서버 도메인: [192.168.11.2]│   │
│  │ 포트: [        8088      ] │   │
│  │                            │   │
│  │ 🔘 UDP  TCP  WebSocket   │   │
│  │                            │   │
│  │ WebSocket 서버:            │   │
│  │ [ws://192.168.11.2:8088/ws]│   │
│  └─────────────────────────┘   │
│                                 │
│  [   SIP 등록   ]              │
│                                 │
│  상태: 미등록                   │
└─────────────────────────────────┘
```

#### SIP 계정 정보 입력

| 필드 | 설명 | 기본값 | 비고 |
|------|------|--------|------|
| **내선 번호** | SIP 계정의 내선 번호 | - | 1001-1004 (UDP), 1101-1104 (WebSocket) |
| **비밀번호** | SIP 계정 비밀번호 | - | PRD 서버 비밀번호 |
| **서버 도메인** | SIP 서버 주소 | 192.168.11.2 | PRD 서버 IP |
| **포트** | SIP 서버 포트 | 5060 (UDP), 8088 (WebSocket) | 전송 프로토콜에 따라 다름 |
| **전송 프로토콜** | SIP 전송 방식 | UDP | UDP/TCP/WebSocket/WSS 선택 |
| **WebSocket 서버** | WebSocket URL | ws://192.168.11.2:8088/ws | WebSocket 프로토콜 시 필수 |

### 3.3 빠른 연결

로그인 화면 하단에 **빠른 연결** 버튼이 있습니다.

| 버튼 | 내선 번호 | 비고 |
|------|-----------|------|
| 1001 | 1001 | UDP 프로토콜 (Mobile 사용) |
| 1002 | 1002 | UDP 프로토콜 (Mobile 사용) |
| 1003 | 1003 | UDP 프로토콜 (Mobile 사용) |
| 1004 | 1004 | UDP 프로토콜 (Mobile 사용) |
| 1101 | 1101 | WebSocket 프로토콜 (Web/Mobile 사용) |
| 1102 | 1102 | WebSocket 프로토콜 (Web/Mobile 사용) |
| 1103 | 1103 | WebSocket 프로토콜 (Web/Mobile 사용) |
| 1104 | 1104 | WebSocket 프로토콜 (Web/Mobile 사용) |

**사용 방법:**
1. 원하는 내선 번호 버튼을 누릅니다.
2. 내선 번호 필드에 자동 입력됩니다.
3. 비밀번호를 입력합니다.
4. "SIP 등록" 버튼을 누릅니다.

## 📞 4. SIP 등록

### 4.1 등록 방법

1. SIP 계정 정보를 모두 입력합니다.
2. "SIP 등록" 버튼을 누릅니다.
3. 앱이 SIP 서버에 연결을 시도합니다.
4. 등록이 성공하면 상태가 "등록됨"으로 변경됩니다.

### 4.2 등록 상태 확인

| 상태 | 표시 | 색상 | 의미 |
|------|------|------|------|
| 미등록 | "미등록" | 회색 | SIP 등록되지 않음 |
| 연결 중 | "연결 중..." | 파란색 | SIP 서버에 연결 중 |
| 연결됨 | "연결됨" | 파란색 | SIP 서버에 연결됨 (등록 전) |
| 등록됨 | "등록됨" | 녹색 | SIP 등록 성공 |
| 오류 | "오류: [오류 메시지]" | 빨간색 | SIP 등록 실패 |

### 4.3 등록 해제

등록된 상태에서 "등록 해제" 버튼을 누르면 SIP 등록이 해제됩니다.

```
└─────────────────────────────────┘
```

### 5.2 번호 입력

- **키패드**: 0-9, *, # 버튼을 사용하여 전화번호를 입력합니다.
- **삭제**: 번호 입력 필드 우측의 "✕" 버튼을 눌러 마지막 숫자를 삭제합니다.
- **전체 삭제**: 번호 입력 필드를 longue press 또는 "C" 버튼을 누릅니다.

### 5.3 통화 시작

1. 다이얼러 화면에서 상대방 내선 번호를 입력합니다.
   - 예: 1102 (Web 클라이언트) 또는 1002 (Mobile 클라이언트)
2. "호출" 버튼을 누릅니다.
3. 앱이 상대방에게 통화를 연결합니다.

## ⚠️ 8. 문제 해결

### 8.1 일반적인 문제

| 문제 | 원인 | 해결 방법 |
|------|------|------------|
| **SIP 등록 실패** | 잘못된 계정 정보 | 내선 번호, 비밀번호, 서버 주소를 확인하세요 |
| | 네트워크 연결 문제 | Wi-Fi 또는 모바일 데이터 연결을 확인하세요 |
| | 서버 연결 실패 | SIP 서버가 실행 중인지 확인하세요 |
| **등록된 상태에서 통화 실패** | 상대방이 등록되지 않음 | 상대방이 SIP 등록되어 있는지 확인하세요 |
| | 포트 차단 | 방화벽 설정을 확인하세요 (UDP 5060, TCP 8088) |
| **영상 표시되지 않음** | 카메라 권한 거부 | 설정 > Kibal Mobile > 카메라 접근 권한 허용 |
| | 카메라 사용 중 | 다른 앱에서 카메라를 사용 중인지 확인하세요 |
| **소리 들리지 않음** | 마이크 권한 거부 | 설정 > Kibal Mobile > 마이크 접근 권한 허용 |
| | 스피커 mute | "스피커" 버튼을 눌러 스피커를 켜세요 |
| **통화 끊김** | 네트워크 문제 | 네트워크 연결을 확인하세요 |
| | 서버 문제 | Asterisk 서버 상태를 확인하세요 |

### 8.2 오류 메시지

| 오류 메시지 | 의미 | 해결 방법 |
|-------------|------|------------|
| "SIP 서버에 연결할 수 없습니다" | SIP 서버 연결 실패 | 서버 주소, 포트, 네트워크 확인 |
| "인증 실패" | 잘못된 비밀번호 | 비밀번호를 확인하세요 |
| "등록 거부" | 서버에서 등록 거부 | 내선 번호가 유효한지 확인하세요 |
| "카메라 접근 거부" | 카메라 권한 거부 | 설정에서 카메라 권한 허용 |
| "마이크 접근 거부" | 마이크 권한 거부 | 설정에서 마이크 권한 허용 |
| "통화 중 오류 발생" | 통화 중 오류 | 네트워크 연결 확인, 다시 시도 |
