# 회의 영상 테스트 절차서 (v0.0.18~v0.0.20)

**날짜**: 2026-11-12
**버전**: v1.0
**환경**: 서버 192.168.0.3, 1101 MacPro(카메라 없음), 1102 MacBook, 1103 iMac — 각자 내선 고정, 표시 이름 입력

| ID | 시나리오 | 절차 | 기대 결과 | 로그 확인 |
|----|---------|------|----------|----------|
| TC-C1 | 참가자 카드 | 3자 6000 입장 | 전원 카드, 1101 "영상 없음", 이름 배지 | `grep <ext> "CONFERENCE participants"` |
| TC-F1 | 전체 화면 진입 | 큰 화면 더블클릭 | 창 전체화면, 영상만, 버튼 미표시 | `fullscreenEnter` |
| TC-F2 | 전체 화면 복귀 | 더블클릭 / Esc | 버튼 깜빡임·오동작 없이 복귀 | `fullscreenExit`, `hangupPressed` 없음 |
| TC-F3 | 1:1 전체 화면 | 1:1 원격 영상 더블클릭 | 동일 | `screen=call` |
| TC-S1 | 입장 자동 동기화 | 2자 진행 중 3번째 입장 | 기존 영상 유지/2초 내 복구 | `VIDEO resync reason=auto:join` (전원) |
| TC-S2 | 퇴장 자동 동기화 | 1명 퇴장 | 남은 영상 유지 | `auto:leave` |
| TC-S3 | 수동 전체 동기화 | 한 명이 "영상 동기화" 클릭 | 전원 5초 내 리프레시 | 클릭자 `manual`, 나머지 `auto:remote:<ext>` |
| TC-S4 | 서버 미응답 | OPS 중지 후 버튼 | "내 화면만 동기화" 안내, 내 화면 리프레시 | `manual` |

명령:
```bash
./scripts/ops_client_logs.sh grep 1102 "VIDEO resync" 10
./scripts/ops_client_logs.sh grep 1103 "fullscreen" 10
curl -s "http://192.168.0.3:8091/api/conference/6000/participants?extension=1101" -H 'X-Client-Key: dev-kibal-clients-2026'
```
