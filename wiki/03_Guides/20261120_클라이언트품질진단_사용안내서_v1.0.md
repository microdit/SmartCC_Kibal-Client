## 1. 설정 메뉴에서 할 수 있는 일

| 항목 | 위치 | 동작 |
|------|------|------|
| 로그보내기 | 설정 → 로그 전송 → **로그보내기** | 자동(즉시+5분 주기) / 즉시(1회) 전송 |
| 품질 지표 보기 | 설정 → **테스트 결과 · 품질 지표** | OPS 로그 기반 표+그래프, 진단·조치 의견 |
| 영상 품질 | 설정 → **영상 품질 (수동 테스트)** | 320p~4K × 15/24/30/60fps 선택 후 적용 |

---

## 2. 통화 중 전체화면 진단

1. 1:1 통화 또는 회의실에서 전체화면 진입.
2. 하단 컨트롤의 **속도계 아이콘(전송속도 진단)** 클릭.
3. 우측 상단에 실시간 패널 표시, 다시 누르면 종료.

| 구분 | 표시 |
|------|------|
| 영상 | 해상도, 코덱, 현재/평균 fps, 현재/평균 bitrate, 손실/freeze/PLI/NACK |
| 음성 | 코덱, 현재/평균 bitrate, jitter, 손실 |
| 네트워크 | 현재/평균 RTT, 가용 송신량, ICE 상태 |
| 판정 | 양호 / 프레임 저하 / 품질 저하 / ICE 점검 중 |

---

## 3. 수동 품질 테스트 권장 절차

1. 기본 `자동` 모드로 통화 품질 확인.
2. 필요 시 720p/30fps → 1080p/30fps → 4K/30fps 순으로 변경하며 전체화면 진단 패널 비교.
3. 무선/유선 전환 시 `collect-test-metrics.sh`로 근거 로그 수집.
4. 테스트 후에는 `자동`으로 복귀 권장.

> 4K는 카메라 지원 여부에 따라 가까운 해상도로 fallback될 수 있습니다. 통화 중 변경 시 카메라가 잠시 재시작됩니다.

---

## 4. 문제 해결

| 증상 | 조치 |
|------|------|
| 품질 지표가 '데이터 없음' | 로그보내기 → 즉시보내기 실행 후 새로고침 |
| 그래프가 비어 있음 | OPS 주소/키 확인, 전송 모드가 '끄기'인지 확인 |
| 진단 패널이 'ICE 점검 중' | 회의실 재입장, SIP 등록 확인 |
| 수동 품질 적용 후 앱 불안정 | `자동` 모드로 복귀, 앱 재시작 |
