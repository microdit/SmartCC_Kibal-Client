## 0. 도메인 확인 (중요)

- **올바른 도메인**: `appletreeda.synology.me` → `211.253.173.236`
- `appletree.synology.me`는 **다른 IP(`46.126.111.211`)**이며 인증서 SAN에도 없습니다. 절대 사용하지 마세요.

```bash
dig +short appletreeda.synology.me
openssl x509 -in ~/Downloads/dev/SmartCC_Kibal/deploy/dev/certs/fullchain.pem \
  -noout -subject -ext subjectAltName
```

## 2. 외부망 사전 점검 (외부 단말에서 실행)

```bash
nc -zv appletreeda.synology.me 8089
openssl s_client -connect appletreeda.synology.me:8089 \
  -servername appletreeda.synology.me -brief </dev/null
curl -s -o /dev/null -w '%{http_code}\n' \
  https://appletreeda.synology.me:8089/ws
```

기대값: TCP 성공, TLS Verification OK, HTTP **426 Upgrade Required**.

---

## 3. 클라이언트 설정

1. `v0.0.44` DMG 설치:
   `macos-client/build/macos/Build/Products/Release/macos_client_v0.0.44.dmg`
2. 앱 실행 → 설정 → 연결 설정:
   - SIP 도메인: `appletreeda.synology.me`
   - WebSocket: `wss://appletreeda.synology.me:8089/ws`
   - Ops 주소: 내부 주소로 두어도 무방(외부 접근 불가)
3. 로그인 화면에서 내선/비밀번호 입력 후 등록.
   - OPS 인증 실패가 떠도 **SIP 등록 성공 시 자동 로컬 인증**이 적용됩니다(v0.0.39+).
4. 등록 상태가 `registered`가 되면 성공.

## 4. 통화 테스트

### 4.1 1:1
- 외부 단말(1103) ↔ 내부 단말(1102) 호출.
- 전체화면에서 **전송속도 진단** 버튼 클릭.
- 확인: ICE `Completed`, audioLost 0, video 30fps 근처, vLost 증가 없음.

### 4.2 회의실 6700
- 외부 단말로 6700 입장.
- AI봇(7001) 영상 수신 확인.
- 진단 패널에서 영상/음성/네트워크 지표 확인.

## 5. 로그 수집 및 판정

```bash
cd ~/Downloads/dev/SmartCC_Kibal-Client
OPS_URL=http://192.168.11.5:8091 ./scripts/collect-test-metrics.sh 1103 external-wss 10
OPS_URL=http://192.168.11.5:8091 ./scripts/ops_client_logs.sh grep 1103 'AUTH\|REGISTER\|video summary\|media summary' 40
```

앱에서 **설정 → 로그보내기 → 즉시보내기(1회)**를 눌러 현재 상태를 바로 업로드할 수 있습니다.

성공 기준:

| 지표 | 기준 |
|------|------|
| SIP | REGISTER 200 OK |
| 인증 | `AUTH verifyResult state=localVerified` |
| ICE | `RTCIceConnectionStateCompleted` |
| 오디오 | `audioLost=0` |
| 영상 | `in=1280x720@30fps`, `vLost` 증가 없음 |
| 진단 패널 | 판정 `양호` |

## 6. 실패 시 대응

| 증상 | 확인 |
|------|------|
| TCP 8089 실패 | IPTime1 포트포워딩 재확인 |
| TLS 인증 실패 | 도메인 오타(`appletree` 금지), 인증서 만료 확인 |
| REGISTER 실패 | 다이제스트 비밀번호 확인, WSS URL 확인 |
| 오디오만 됨 | UDP 10000-10200 포트포워딩 확인 |
| 영상만 끊김 | 대칭NAT/CGNAT 의심 → TURN(coturn) 필요 |
| OPS 인증 실패 | 정상. SIP 로그인으로 로컬 인증 완료되는지 확인 |
