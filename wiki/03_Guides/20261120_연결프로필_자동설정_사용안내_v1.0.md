## 1. 개요

설정의 `연결 설정 (DEV)` 문구를 **연결 프로필 선택 방식**으로 변경했다. DEV / PRD / 외부망 프로필을 저장하고, 연결 가능한 서버에서 `/api/client/config`를 받아 자동 설정한다.

---

## 2. 프로필별 기본값/탐색 순서

| 프로필 | 기본 도메인 | WS | OPS 탐색 후보 |
|--------|------------|----|---------------|
| DEV | `192.168.11.5` | `ws://192.168.11.5:8088/ws` | `http://192.168.11.5:8091`, `http://MacPro.local:8091` |
| PRD | `192.168.11.3` | `ws://192.168.11.3:8088/ws` | `http://192.168.11.3:8091`, `http://nas2:8091` |
| 외부망 | `appletreeda.synology.me` | `wss://appletreeda.synology.me:8089/ws` | `https://appletreeda.synology.me:8091` |

> 외부망은 OPS 8091을 의도적으로 개방하지 않았으므로 자동 탐색이 실패할 수 있습니다. 이 경우 수동 입력이 정상 동작이며, SIP 로그인 성공 시 로컬 인증이 적용됩니다.

---

## 3. 사용법

1. 설정 → 연결 설정 카드에서 프로필 선택.
2. 프로필을 바꾸면 해당 프로필의 저장값(또는 기본값)이 필드에 채워집니다.
3. **서버에서 자동 설정**을 누르면 후보 OPS 순으로 `/api/client/config`를 조회합니다.
   - 성공: 도메인/포트/WS/OPS 주소가 자동으로 채워지고 `자동 설정을 받았습니다` 표시.
   - 실패: `연결되는 서버가 없습니다. 수동으로 입력하세요` 표시.
4. 수정 후 **연결 설정 저장**을 누르면 프로필별로 저장됩니다(`connection-profiles.json`).

---

## 4. 로그 서버 연동 및 연결 테스트 (v0.0.47~48)

- 프로필을 바꾸면 **로그 전송 URL도 함께 변경**됩니다(`<프로필 OPS 주소>/api/client-logs`).
  - DEV: `http://192.168.11.5:8091/api/client-logs`
  - PRD: `http://192.168.11.3:8091/api/client-logs`
  - 외부망: `https://appletreeda.synology.me:8091/api/client-logs`
- 설정 → 연결 설정 카드의 **연결 테스트** 버튼으로 프로필별 경로를 점검합니다.
  - OPS `/api/client/config` (후보 순차)
  - WS `host:port` TCP 연결
  - 로그 서버 응답
  - 결과는 성공/실패 아이콘과 HTTP 상태·오류 메시지로 표시됩니다.

> 외부망에서 OPS 8091은 IPTime/NAS 방화벽으로 차단되어 있어 로그 업로드가 실패할 수 있습니다. 이때 클라이언트는 로그를 로컬에 보관하고, 내부망 복귀 시 재전송합니다. SIP 통화(WSS 8089)와 로그 전송(OPS 8091)은 별개 경로입니다.

---

## 5. 자동 설정 동작

- 서버 응답의 `secure` 값이 있으면 `http/ws` → `https/wss`로 자동 전환합니다.
- 프로필 전환 시 현재 필드 값은 이전 프로필에 자동 저장됩니다.
- 선택한 프로필은 앱 재시작 후에도 유지됩니다.
