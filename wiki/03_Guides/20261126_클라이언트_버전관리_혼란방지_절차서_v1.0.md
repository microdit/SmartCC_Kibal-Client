## 1. 원칙

1. **버전은 항상 상승한다.** 과거 버전으로 되돌리지 않는다.
2. **기준은 원격 브랜치의 최신 pubspec이다.** 로컬 기억/이전 세션 값을 쓰지 않는다.
3. **숫자 수동 지정 금지.** `release_macos.sh`의 자동 bump(기본 patch)를 사용하거나, 명시적 지정 시 반드시 원격 최신 +1을 확인한다.

## 2. 빌드 전 필수 확인

```bash
cd /Users/microdit/Downloads/dev/SmartCC_Kibal-Client
git fetch origin feature/external-network-access
git show origin/feature/external-network-access:macos-client/pubspec.yaml | grep '^version:'
grep '^version:' macos-client/pubspec.yaml
```

두 값이 다르면 **먼저 로컬을 원격 기준으로 맞춘 뒤** 버전 +1 한다.

## 3. 안전한 버전 변경

```bash
# 원격 최신이 0.0.63+64 라면 → 0.0.64+65
sed -i '' -E 's/^version: .*/version: 0.0.64+65/' macos-client/pubspec.yaml
/usr/libexec/PlistBuddy -c "Set :CFBundleShortVersionString 0.0.64" macos-client/macos/Runner/Info.plist
/usr/libexec/PlistBuddy -c "Set :CFBundleVersion 65" macos-client/macos/Runner/Info.plist
```
