# macOS 클라이언트 버전 발행 가이드 (v1.0)

| 항목 | 내용 |
|------|------|
| **문서 ID** | GUIDE-20261114-RELEASE-001 |
| **작성일** | 2026-11-14 |
| **대상** | SmartCC Kibal macOS Client (`macos-client/`) |
| **스크립트** | `macos-client/scripts/build_macos.sh`, `macos-client/scripts/release_macos.sh` |

## 1. 요약: 빌드 vs 발행

| 구분 | 명령 | 버전 | 용도 |
|------|------|------|------|
| **빌드** | `./scripts/build_macos.sh release` | **유지** (`pubspec.yaml` 그대로) | 현재 버전 재빌드/DMG 재생성 |
| **발행** | `./scripts/release_macos.sh [patch\|minor\|major\|X.Y.Z]` | **증가**(기본 patch, build+1) | 버전 올려 검증·빌드·DMG·체크섬(+선택 커밋/태그) |

- 버전 단일 소스: `macos-client/pubspec.yaml` (`version: X.Y.Z+build`). 빌드 시 `Info.plist`(CFBundleShortVersionString/CFBundleVersion)와 `--dart-define=APP_VERSION=vX.Y.Z`가 동기화됨.
- 실행 위치: `SmartCC_Kibal-Client/macos-client/`

## 2. `build_macos.sh` (버전 유지)

```bash
cd macos-client
./scripts/build_macos.sh release          # Release 빌드 + DMG
./scripts/build_macos.sh debug            # Debug 빌드
./scripts/build_macos.sh release --no-dmg # DMG 생략
```

- 출력: `build/macos/Build/Products/Release/macos_client.app`, `macos_client_vX.Y.Z.dmg`
- 버전 번호를 변경하지 않으므로 **같은 버전으로 재빌드**할 때 사용.

## 3. `release_macos.sh` (버전 발행)

```bash
cd macos-client
./scripts/release_macos.sh                  # patch: 0.0.26 → 0.0.27, build +1
./scripts/release_macos.sh minor            # 0.0.26 → 0.1.0
./scripts/release_macos.sh major            # 0.0.26 → 1.0.0
./scripts/release_macos.sh 0.0.30           # 지정 버전
./scripts/release_macos.sh --no-bump        # 버전 유지 재빌드(검증/DMG/체크섬 수행)
```

### 옵션
| 옵션 | 설명 |
|------|------|
| `--skip-tests` | `flutter analyze` / `flutter test` 생략 (긴급/환경 이슈 시) |
| `--commit` | `pubspec.yaml`, `macos/Runner/Info.plist` 버전 변경 커밋 + 태그 `macos-vX.Y.Z` 생성 (**푸시는 별도**) |
| `--install` | 빌드 앱을 `/Applications`에 설치(기존 앱 교체, quarantine 제거) |

### 수행 단계
1. 사전 점검 (flutter/xcodebuild, 호스트/아키텍처)
2. 버전 결정 및 `pubspec.yaml` 갱신 (`--no-bump` 제외)
3. `flutter pub get`
4. `flutter analyze` / `flutter test` (`--skip-tests` 시 생략)
5. Release 빌드 + DMG (`build_macos.sh` 호출)
6. 산출물 점검 (Info.plist 버전, 아키텍처, codesign, DMG 내용/Applications 링크)
7. 체크섬 생성: `macos_client_vX.Y.Z.dmg.sha256`
8. (선택) `/Applications` 설치
9. (선택) 커밋 `release(macos): vX.Y.Z+build` + 태그 `macos-vX.Y.Z`

### 산출물
- `build/macos/Build/Products/Release/macos_client.app`
- `build/macos/Build/Products/Release/macos_client_vX.Y.Z.dmg`
- `build/macos/Build/Products/Release/macos_client_vX.Y.Z.dmg.sha256`

## 4. Git 커밋·태그·푸시

`--commit` 사용 시 로컬 커밋/태그만 생성되며 **자동 푸시되지 않음**.

```bash
# --commit 사용 후
git push origin <branch>
git push origin macos-vX.Y.Z

# --commit 미사용 시 수동 예시
git add macos-client/pubspec.yaml macos-client/macos/Runner/Info.plist
git commit -m "release(macos): vX.Y.Z+build"
git tag macos-vX.Y.Z
git push origin <branch> && git push origin macos-vX.Y.Z
```

- 기능/수정 커밋과 릴리스(버전 bump) 커밋을 분리하는 것을 권장.
- NAS `dev/prd` 미접속 시 `origin` 기준으로 동기화(프로젝트 정책).

## 5. 배포/설치 (다른 Mac)

```bash
xattr -d com.apple.quarantine ~/Downloads/macos_client_vX.Y.Z.dmg
open ~/Downloads/macos_client_vX.Y.Z.dmg   # 앱을 /Applications로 끌어다 놓기
xattr -dr com.apple.quarantine /Applications/macos_client.app
```

- ad-hoc 서명 빌드 기준. 무결성 확인: `shasum -a 256 -c macos_client_vX.Y.Z.dmg.sha256`

## 6. 참고/주의
- `packages/flutter_webrtc`, `packages/sip_ua`는 로컬 path + `dependency_overrides` 사용(패치 반영). 릴리스 빌드 시 해당 수정 포함 여부 확인.
- Ops 연동(빠른연결/회의실/설정/로그)은 서버 도달 및 `X-Client-Key`(`AppConstants.opsClientKey`) ↔ 서버 `OPS_CLIENT_KEY` 일치 필요. 미일치 시 일부 기능 폴백.
- CocoaPods 통합 제거 안내가 빌드 로그에 출력될 수 있으나 SwiftPM 전환은 별도 작업. `--skip-tests` 사용 시 analyze/test 미수행이므로 릴리스 전 통과 권장.
