## 5. 금지/주의 사항

- **`pod deintegrate` / `Podfile` 삭제 금지**: Swift Package 전환은 별도 승인 후 진행. 이번에는 Podfile을 유지하고 CocoaPods를 설치한다.
- **`flutter pub upgrade` 금지**: 재현성 위해 `flutter pub get`만 사용(버전 고정 유지).
- **Flutter 채널 변경/업그레이드 금지**: 3.47.9 stable 고정.
- **서버 설정 변경 금지**: `confbridge.conf`, `pjsip.conf`, `video_mode`, `Answer()` 등 수정 금지. 진단은 조회/로그만.
- **PRD(`192.168.11.2`) 사용 금지**: DEV(`192.168.11.39`)만 사용.
- **커밋/강제푸시 금지**: 지시받지 않은 커밋·`git push --force` 금지. `Pods/`, `build/`, `macos/Flutter/ephemeral/`, `.dart_tool/`은 커밋 금지(이미 gitignore).
- **시스템 Ruby에 무리한 gem 설치 지양**.
- Android 빌드는 범위 밖(설치하지 말 것).

## 10. (선택) 외부 네트워크 자체 테스트 — `192.168.11.39` 미접속 대비

> **목적**: `192.168.11.39`에 접속하지 않거나, 외부 이동/외부 네트워크 환경에서 클라이언트를 검증해야 할 때,
> **형제 리포 `SmartCC_Kibal/deploy/dev`의 Asterisk를 이 iMac에서 직접 구동**하여 완전 로컬 검증을 수행한다.
> **전제**: 섹션 9(Docker) 설치 완료. 원격 `192.168.11.39`의 데이터/설정은 **일절 사용·변경하지 않는다**.

### 10.1 로컬 Asterisk 스택 기동
```bash
cd /Users/microdit/Downloads/dev/SmartCC_Kibal/deploy/dev
./up.sh            # .env/ops.env 자동 생성 + compose up -d --build + healthcheck + verify.sh
docker compose -f compose.yaml ps   # kibal-dev-asterisk healthy 확인
```
- 포트: SIP 5060/udp, WS 8088/tcp, RTP 10000-10200/udp
- 계정: `1101`~`1104` (비번은 `deploy/dev/.env`의 `SIP_PASSWORD_1101`~`1104`, 기본 `CHANGE_ME_DEV_*`)
- 회의: `6000` (`confbridge.conf`/`extensions.conf`)

### 10.2 클라이언트를 로컬 서버에 연결
- 로그인 화면에서 서버를 `127.0.0.1` (또는 iMac LAN IP), WS `ws://127.0.0.1:8088/ws`로 지정
- 계정 `1101`/`1102`/`1103`, 비밀번호는 `.env` 값
- 2대 이상 클라이언트(또는 `tool/*_probe.dart`)로 `6000` 입장 → `recovered=true`, `audioBytes>0` 확인

### 10.3 외부 네트워크에서 테스트할 때
- `127.0.0.1` 대신 **iMac LAN IP**(예: `192.168.x.x`) 사용
- 방화벽/라우터에서 `5060/udp`, `8088/tcp`, `10000-10200/udp` 인바운드 허용
- RTP 범위(10000-10200)가 막히면 오디오 `audioBytes=0`이 되므로 반드시 개방
- NAT 환경에서는 STUN/ICE 동작 확인 필요(클라이언트 로그의 `iceConnectionState`)

### 10.4 종료
```bash
cd /Users/microdit/Downloads/dev/SmartCC_Kibal/deploy/dev
docker compose -f compose.yaml down
```
