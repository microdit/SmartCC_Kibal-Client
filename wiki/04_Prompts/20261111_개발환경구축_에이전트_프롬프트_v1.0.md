## 3. 실행 단계

### Phase 0 — 사전 확인 (변경 없음)

### Phase 1 — Xcode 라이선스 및 최초 실행
```bash
sudo xcodebuild -license accept
sudo xcodebuild -runFirstLaunch
xcode-select -p              # 기대: /Applications/Xcode.app/Contents/Developer
```

### Phase 2 — CocoaPods 설치 (P0, 핵심)
권장(시스템 Ruby 2.6 회피):
```bash
brew install cocoapods
export LANG=en_US.UTF-8
pod --version               # 기대: 1.16 이상 (예: 1.17.x)
```
- 실패 시 대안 1: `brew update && brew reinstall cocoapods`
- 실패 시 대안 2(비권장, 시스템 Ruby 사용): `sudo gem install cocoapods -n /usr/local/bin`
  - Ruby 2.6에서 gem 빌드 오류가 나면 **rbenv로 Ruby 3.x 설치 후 재시도**:
    ```bash
    brew install rbenv ruby-build
    rbenv install 3.3.6 && rbenv global 3.3.6
    gem install cocoapods
    ```
- **금지**: `sudo gem install cocoapods`를 첫 선택으로 쓰지 말 것(권한/버전 충돌 위험).

### Phase 3 — 프로젝트 의존성 및 Pod 설치
```bash

pod install --repo-update      # 최초 1회는 repo update 필요
```

- 만약 `pod install`이 runner workspace를 갱신하면 `flutter build` 전에 반드시 완료될 것.

### Phase 4 — 정적 검증/빌드

## 5. 금지/주의 사항

- **`pod deintegrate` / `Podfile` 삭제 금지**: Swift Package 전환은 별도 승인 후 진행. 이번에는 Podfile을 유지하고 CocoaPods를 설치한다.
- **`flutter pub upgrade` 금지**: 재현성 위해 `flutter pub get`만 사용(버전 고정 유지).
- **Flutter 채널 변경/업그레이드 금지**: 3.47.9 stable 고정.
- **서버 설정 변경 금지**: `confbridge.conf`, `pjsip.conf`, `video_mode`, `Answer()` 등 수정 금지. 진단은 조회/로그만.
- **PRD(`192.168.11.2`) 사용 금지**: DEV(`192.168.11.39`)만 사용.
- **커밋/강제푸시 금지**: 지시받지 않은 커밋·`git push --force` 금지. `Pods/`, `build/`, `macos/Flutter/ephemeral/`, `.dart_tool/`은 커밋 금지(이미 gitignore).
- **시스템 Ruby에 무리한 gem 설치 지양**.
- Android 빌드는 범위 밖(설치하지 말 것).

## 6. 문제 해결 가이드

| 증상 | 원인 | 조치 |
|------|------|------|
| `CocoaPods not installed or not in valid state` | pod 미설치/비정상 | Phase 2 재확인, `pod --version`, `brew reinstall cocoapods` |
| `pod: command not found` (설치 후) | PATH 미반영 | `brew --prefix`/`eval "$(brew shellenv)"`, 새 셸 재실행 |
| `pod install` 시 Ruby/gem 오류 | 시스템 Ruby 2.6 | rbenv Ruby 3.x로 재시도 |
| `Sandbox: rsync deny` / Xcode 빌드 오류 | Xcode sandbox/DerivedData | Xcode 설정 또는 `flutter clean` 후 재빌드 |
| `Signing for "Runner" requires a development team` | 서명 미설정 | Xcode → Runner → Signing & Capabilities → "Sign to Run Locally" |
| `All plugins are Swift Packages...` 경고 | Podfile 잔존 | **무시 가능**(빌드에는 pod 필요). 전환은 승인 후 |
| 카메라/마이크 권한 | TCC 미승인 | 시스템 설정 > 개인정보 보호 > 카메라/마이크 허용 |
| DEV 8088 접속 실패 | 네트워크/컨테이너 | `nc -z 192.168.11.39 8088`, `docker ps` |
