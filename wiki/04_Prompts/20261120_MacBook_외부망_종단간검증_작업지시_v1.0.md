## 1. 목적

미국 IP VPN 상태에서 외부 프로필(`appletreeda.synology.me`)로 **SIP 등록 → 1:1 통화 → 6700 회의실 → 실시간 품질 지표 → 로그 수집**까지 종단간 검증하고 결과를 wiki에 보고한다.

---

## 2. 사전 준비

1. MacPro가 커밋/푸시한 최신 커밋을 받는다.
   ```bash
   cd ~/Downloads/dev/SmartCC_Kibal-Client
   git fetch --all
   git rebase origin/feature/external-network-access   # 또는 merge
   git status -sb
   ```
2. 최신 DMG 설치/실행:
   `macos-client/build/macos/Build/Products/Release/macos_client_v0.0.49.dmg`
3. 미국 IP VPN이 활성화됐는지 확인:
   ```bash
   curl -s https://api.ipify.org; echo
   ```

## 3. 반드시 지킬 설정

| 항목 | 값 | 금지 |
|------|----|------|
| SIP 도메인 | `appletreeda.synology.me` | `appletree.synology.me`, 공인 IP 직접 |
| WS | `wss://appletreeda.synology.me:8089/ws` | `ws://`, `:8088` |
| OPS/로그 | `http://appletreeda.synology.me:8091` | `https://8091`, `http://211.253.173.236:8091` |
| 프로필 | 외부망 | DEV/PRD |

> OPS 8091은 HTTP-only다. HTTPS는 응답하지 않는다.

## 4. 검증 절차

### 4.1 연결 테스트
1. 설정 → 연결 설정 → 프로필 `외부망` 선택.
2. **연결 테스트** 클릭.
3. 기대 결과:
   - OPS 설정: `HTTP 200` 또는 `401`(인증 요구) → 도달 성공
   - WS 포트: `appletreeda.synology.me:8089` TCP 성공
   - 로그 서버: HTTP 응답

### 4.2 SIP 로그인
1. 로그인 화면 또는 주소록 자동등록으로 `1102` + SIP 비밀번호 입력.
2. 기대 로그: `SIP state -> registered`.
3. OPS 인증 실패가 나도 SIP 등록 성공 시 로컬 인증이 적용된다.

### 4.3 통화/회의
1. 내부 1101과 1:1 통화 → `callEstablished`, `audioLost=0`.
2. 6700 회의실 입장 → AI봇(7001) 영상 수신.
3. 전체화면 진입 → **전송속도 진단** 버튼 클릭 → 패널 캡처/기록.
4. 확인 지표: `in=1280x720@30fps`, `vLost=0`, ICE Completed.

### 4.4 로그 수집
```bash
cd ~/Downloads/dev/SmartCC_Kibal-Client
OPS_URL=http://192.168.11.5:8091 ./scripts/collect-test-metrics.sh 1102 us-vpn-final 10
OPS_URL=http://192.168.11.5:8091 ./scripts/ops_client_logs.sh grep 1102 'video summary' 10
OPS_URL=http://192.168.11.5:8091 ./scripts/ops_client_logs.sh grep 1102 'media summary' 5
```
앱에서 **로그보내기 → 즉시보내기(1회)**도 실행한다.

## 6. 금지 사항

- 비밀값(SIP 비밀번호, OPS 키, `.env`)을 문서/커밋에 기록하지 않는다.
- 서버 방화벽/포트포워딩을 임의로 변경하지 않는다(필요 시 MacPro에 요청).
- OPS 8091을 HTTPS로 바꾸지 않는다.
- 실패 시 추측으로 성공 처리하지 말고 로그 근거를 첨부한다.
