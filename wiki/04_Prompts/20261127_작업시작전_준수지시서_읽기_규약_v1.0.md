## 2. 작업 시작 체크리스트 (반드시 순서대로)

1. **지시서 확인**
   ```bash
   ls wiki/04_Prompts/ | grep -E '준수|작업지시'
   ```
   - 준수 대상: 본 문서 + `20261126_Client_v0.0.64_버전복구_분리검수_작업지시서_v1.0.md` + 답변서
2. **영속 규약 확인**
   ```bash
   grep -n '검수 전\|force\|git add -A\|버전' wiki/03_Guides/20261126_4환경_Git_운영규약_v1.0.md
   grep -n 'git add -A\|검수' docs/AGENTS.md
   ```
3. **버전/브랜치 확인**
   ```bash
   git status --short
   git branch --show-current
   git fetch origin <branch>
   git show origin/<branch>:macos-client/pubspec.yaml | grep '^version:'
   grep '^version:' macos-client/pubspec.yaml
   ```
4. **빌드 가드 확인**: `release_macos.sh`가 원격 최신 대비 역행 차단 + TEST 브랜치 경고를 수행함(2026-11-27 추가). 가드를 무력화하지 말 것.

## 3. 준수 내용 요약 (매번 확인)

| 항목 | 규칙 |
|------|------|
| 브랜치 | 검수 전 산출물은 `test/<topic>`에만. DEV/PRD/EXTERNAL 기준선 직접 push 금지 |
| force push | **승인 없이 금지**. 사람이 fetch/작업한 리모트는 되돌리지 말 것 |
| 버전 | 원격 최신 +1만. 임의 숫자·역행 금지. `release_macos.sh` 가드가 강제 |
| 커밋 | `git add -A` 금지, 명시 파일만 stage |
| 빌드 | analyze/test/DMG/codesign/SHA256/6700 실기 증거 없이 DEV 승격 금지 |
| 재발 방지 | 정책을 읽었다는 근거 없이 "진행해"만으로 커밋/푸시/버전上昇 하지 않음 |
