## 프롬프트 본문

> SmartCC_Kibal-Client / SmartCC_Kibal 두 리포의 통화 품질 개선을 **C → A → D → B 순서**로 진행한다.
>
> **먼저 읽을 문서**
> 1. `docs/보고서/20261112_통화품질_원인규명_작업계획서_v1.0.md` (Client)
> 2. `wiki/03_Guides/20261112_통화품질_테스트절차서_v1.0.md` (Client)
> 3. `wiki/06_Reports/20261112_통화품질_원인규명_분석보고서_v1.0.md` (Client)
> 4. `wiki/09_Knowledge/20261112_SIP_진단지식_v1.0.md` (Client, K1~K12)
> 5. 서버 리포 `wiki/01_Projects/20261112_SIP등록_회의영상_개선_작업계획서_v1.0.md`
>
> **절대 규칙**
> - 로그 귀속은 identity로 확인한다. "1103 로그"라 붙은 파일도 `usr=1102`면 1102 로그다(K1).
> - 시각은 클라이언트 KST / Asterisk UTC(**+9h**)를 병기한다(K2).
> - `freeze`/`pli`/`nack`/`vLost`/`keyframes`/`audioLost`는 **누적 카운터**다. 값 고정 = 이후 이벤트 0건이지 버그가 아니다(K3).
> - `session(video=N)`은 누적 스트림 합계, `videoTracks=A/B`는 실제 RTP 트랙 수다. 혼동 금지(K4).
> - 타임스탬프 3자리는 `toIso8601String()` 정상 동작이다(K7).
> - `pjsip set logger on`은 진단 후 반드시 `off`.
> - 비밀번호·`X-Client-Key`·SIP secret은 문서·로그·커밋에 쓰지 않는다.
>
> **C (최우선) — A10 1201 원격 영상**
> - 현재 `6100` ConfBridge에 `PJSIP/1103-*` + `PJSIP/1201-*` 실통화 중. 스냅샷부터 고정(TC-C1).
> - `core show channel PJSIP/1201-*`에서 `video-1 sendrecv / h264` 확인됨 → **SDP 문제 아님**(K9).
> - `confbridge show profile bridge kibal_bridge_ft` + 발화자 전환으로 3후보(발화자 미전달 / 자기 루프백 / `max_video_streams=1`)를 판정(TC-C4).
> - 결과를 서버 `08_Experiments`·ADR로 기록하고 `confbridge.conf` 변경은 ADR 후에만 적용.
>
> **A — 404 재발 방지**
> - 원인 확정: `messages:1261-1265` / `security:2200-2203` = 1103 AOR contact 부재(K5).
> - `pjsip set logger on` 후 1103 재로그인 반복 → `remove_existing=yes` contact 공백 실측(TC-A6, K6).
> - 서버 ADR-004로 `remove_existing`/qualify/expiration 결정, 클라이언트는 WS 재연결 시 재REGISTER 보장.
> - 3시점(등록 직후/갱신 중/만료 직후) 회귀(TC-A8).
>
> **D — 코드 결함 2건**
> - D1: `sip_client.dart:624-638` `_acceptReinvite`의 `accept({})`에 `_receiveVideoOptions()` 병합 → ADR-008(K11).
> - D2: `media_manager.dart:377-410, 575-590` 통화 중 stale `_remoteSessions` 정리 → `session(video)` 누적 제거.
> - D3: `1102.meta.json` app_version으로 로그 빌드 기준선 확정.
> - `flutter analyze` 0건 / `flutter test` 전 통과 / `release_macos.sh` DMG + sha256 기록.
>
> **B — 품질 검증(마지막)**
> - D2 반영 후 60분 6000 통화. out fps ≥ 25 유지가 합격(TC-B1).
> - `02:44–02:46` 상당 구간에서 CPU/인코더 사용률 동시 계측(K10 체크리스트).
> - `01:15:03` `1280x720→640x480`(`limit=none`) 경로 특정(TC-B5).
>
> **매 단계 기록**
> - `wiki/07_Logs/작업로그_20261112.md`(양 리포), `docs/_작업이력/2026-11-12.md`(양 리포)에 KST/UTC 병기로 기록.
> - 실패 시에도 롤백(설정 원복·logger off·통화 종료)을 남긴다.
> - 완료 시 분석보고서를 v1.1로 갱신하고 `./scripts/git-sync.sh --auto --no-deploy`로 양 리포 동기화(NAS 미도달은 SKIP).
>
> **하지 말 것**
> - A10 모드 변경(공장 초기화), 관리자 비밀번호 변경.
> - 문서 없이 코드·서버 설정 먼저 수정.
