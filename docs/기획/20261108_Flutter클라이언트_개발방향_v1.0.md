4. 문제 ③ SIP MD5 인증 문제
Flutter만으로 해결되지 않음
이 부분이 가장 중요합니다.

현재 SmartCC Kibal 프로젝트는 Asterisk PJSIP를 사용하고 있습니다.

SIP Digest 인증은 다음과 같이 작동합니다.

클라이언트가 REGISTER 요청

Asterisk가 401 인증 Challenge 반환

클라이언트가 username, realm, password, nonce 등을 이용해 Digest 응답 생성

Authorization 헤더를 포함해 REGISTER 재전송

Asterisk가 검증하고 200 OK 반환

Asterisk 공식 문서에 따르면 Digest 인증은 MD5를 기본적으로 사용하며, password=에 평문을 넣어 서버가 인증 응답을 계산하도록 하거나, password_digest에 사전 계산된 자격 증명을 넣을 수 있습니다. 사전 계산값은 단순한 MD5(password)가 아니라 username:realm:password를 해시한 값입니다.
