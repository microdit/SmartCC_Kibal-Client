## 4. 실기 재검증 절차 (사용자)

1. 3대에 `macos_client_v0.0.14.dmg` 설치 (메뉴 → 로그 전송 설정은 기본값 유지 가능)
2. **다자간**: 각 단말 다이얼러에서 `6000` 통화
   - 기대: 회의 화면이 열리고 하단에 **원격 참가자 카드**, 카드 클릭 시 큰 화면 전환, 우상단 **내 영상 PIP**
   - 1101(카메라 없음)의 "내 영상" 카드는 "카메라 없음" 표시
3. **직접 통화**: 1101 → 1103 호출, 1103에서 수락 → 통화 성립(이전 603/487 실패 재현 여부)
4. **네트워크 분리**: 1102/1103을 유선 또는 5GHz로 두고 3자 5분 유지
5. 로그 전달 불필요 — 에이전트가 OPS에서 직접 확인
   ```bash
   ./scripts/ops_client_logs.sh grep 1102 "media summary"
   ./scripts/ops_client_logs.sh grep 1103 ERROR
   ```

### 판정 기준

- [ ] 6000에서 원격 참가자를 카드로 선택해 큰 화면으로 볼 수 있음
- [ ] 수신 수락 ERROR 0건, 1101↔1103 직접 통화 성립
- [ ] `media summary`의 `videoTracks` 활성 수가 참가자 수 이내
- [ ] `media summary`가 30초마다 기록되고 `WARN_NO_AUDIO` 없음
- [ ] 유선/5GHz에서 408 ICE 실패 미발생(발생 시 네트워크 원인 확정)
