## 1. 개요

Intel Mac에서 완료된 macOS 클라이언트(macos-client)를 카메라 보유 MacBook/iMac으로 가져와
다음 세 가지를 수행했다.

1. **영상 송수신 실기 검증** — 1:1 통화 및 ConfBridge 3자 회의
2. **실행 로그 인프라 구축** — 배포 DMG에서도 원인 분석이 가능하도록
3. **실측 발견 결함의 즉시 수정** — UI 레이아웃, 등록 흐름, 미디어 렌더링, 크래시

원인 규명은 전부 **자체 수집 로그**(AppLogger + 네이티브 로그 뷰어)로 수행했으며,
각 결함은 로그 라인을 근거로 아래 매트릭스에 기록했다.

## 3. 문제별 원인·해결 매트릭스

## 4. 신규 구축 인프라

### 4.1 AppLogger (Dart)
- 경로: 컨테이너 `~/Library/Containers/com.microdit.macosClient/Data/Library/Application Support/com.microdit.macosClient/logs/app.log`
- 직전 세션은 `app-prev.log`로 보관, 2MB 자동 rotate
- 5초 동일 로그 스팸 필터 (요약 라인 기록으로 유실 방지)
- `FlutterError.onError`/`PlatformDispatcher.onError` 글로벌 후커 — 프레임워크/런타임 예외까지 파일 적립
- 세션 식별자: `usr=<내선>@<domain> host=<기기명> ip=<로컬IP>`
- 레벨: DEBUG / INFO / EVENT / WARN / ERROR

### 4.2 네이티브 로그 뷰어 (macOS)
- `창 > 실행 로그 보기` (⌥⌘L) — `MainMenu.xib`에 정의 (programmatic 등록 미발견 → xib 확정)
- NSTextView 실시간 폴링(1초), 자동 스크롤, Find Bar, `폴더에서 열기`/`전체 복사` 버튼
- 레벨 팝업 필터: 전체 / DEBUG / INFO / EVENT / WARN / ERROR

### 4.3 미디어 테스트 화면 (신규 `/mediaTest`)
- WebRTC `enumerateDevices()` 카메라/마이크 목록 드롭다운, 선택 즉시 재실험 반영
- 마이크 레벨 미터 — 네이티브 `AVAudioRecorder` metering (`MethodChannel kibal/media_test`)
- 감도(게인) 0.5x~4.0x 슬라이더 (표시 배율 + 적용 시 기록)
- 카메라 실시간 프리뷰 (16:9)
- 접근 경로: 다이얼러 우상단 ⋮ → `마이크/카메라 테스트`

### 4.4 버전 표기 체계
- 단일 소스: `pubspec.yaml` version → `scripts/build_macos.sh`가 전파
  - DMG: `macos_client_v0.0.2.dmg`
  - `--dart-define=APP_VERSION=v0.0.2` → 타이틀바 `Kibal macOS v0.0.2`
  - Info.plist `CFBundleShortVersionString`
- 코드 수정 시 pubspec version을 올림 → 빌드 산물이 빌드 시점 식별 가능

### 4.5 로그인 화면 빠른 연결
- `1101/1102/1103` 3계정 버튼 → 클릭 시 계정 + 암호(`<내선>pass`) 동시 자동 입력
- `AppConstants.devQuickAccounts` 상수 맵 관리
