## 3. SIP 기능 검증 (DEV Asterisk)

### CT-M06 REGISTER / UNREGISTER

```
flutter run -d macos --debug -t tool/register_probe.dart \
  --dart-define=SIP_USERNAME=1102 --dart-define=SIP_PASSWORD=1102pass
```

```
>>> init 1102@192.168.11.39 (ws://192.168.11.39:8088/ws)
>>> init=true state=SipClientState.connected
SIP/2.0 401 Unauthorized        ← 정상 Digest 챌린지 1회
SIP/2.0 200 OK                  ← 인증 성공
>>> register=true state=SipClientState.registered
>>> unregister=true state=SipClientState.unregistered
>>> RESULT: REGISTER_OK
```

- ✅ PASS. MD5 401 루프 없음(401은 정상 인증 절차). 인증서 없이 등록 성공.

### CT-M07 1:1 통화 (1102 → 1103, 자동 수신)

```
flutter run -d macos --debug -t tool/call_probe.dart
```

```
[CALLEE] incoming 1102 → accept
[CALLEE] REMOTE STREAM video=0 audio=1
[CALLER] REMOTE STREAM video=0 audio=1
[CALLER] established=true remoteStreams=1
[CALLEE] established=true remoteStreams=1
>>> RESULT: CALL_OK
```

- ✅ PASS. INVITE → 180 → 200 OK → ACK → DTLS-SRTP 미디어 → BYE 전 구간 정상.
- 양방향 원격 오디오 스트림 수신 확인. 통화 5초 유지 후 정상 종료.

### CT-M08 3자 회의 (1102/1103/1104 → ConfBridge 6000)

```
flutter run -d macos --debug -t tool/conference_probe.dart
```

```
=== confbridge list (회의 중, Asterisk CLI) ===
6000    Users: 3    Locked: No    Muted: No

[P1102] established=true remoteStreams=1
[P1103] established=true remoteStreams=1
[P1104] established=true remoteStreams=1
>>> RESULT: CONFERENCE_OK
```

- ✅ PASS. Asterisk가 실제 참가자 3명을 인식. 각 참가자가 브리지 믹스 원격 스트림 수신.
- 10초 유지 후 전원 정상 퇴장.

## 5. 발견 및 해결된 결함

| 결함 | 원인 | 조치 |
|------|------|------|
| iOS SIP 미동작 | `flutter_sip 0.0.8`이 Android 전용 | `sip_ua`로 교체 (ADR-004) |
| macOS 빌드 불가 | desktop 프로젝트 미생성 | `flutter create --platforms=macos` 스캐폴 |
| Swift 컴파일 오류 | `AppDelegate` 잘못된 시그니처 | 표준 macOS 템플릿으로 재작성 |
| `Future already completed` | Completer 중복 완료 | `_completeRegister`/`_completeTransport` 가드 |
| `getUserMedia NotFoundError` | 카메라 없는 Mac | 음성 전용 자동 대체(발신/수신/로컬 미디어) |
| 통화 종료 다이얼로그 미표시 | 종료 조건 오류(`!isInCall && !isRegistered`) | `_wasInCall` 추적으로 수정 |
| `ephemeral/*` Git 추적 | 기존 커밋에 포함됨 | 인덱스 제거 + `.gitignore` 유지 |

### CT-M07v 1:1 영상통화 재검증 (카메라 있음)
