## 2. 목표

1. **W1(H5)**: 1201 등록/중복 채널 정리 후 1:1·6100 재실기 가능 상태 확보.
2. **W2(F1/H6)**: v0.0.24 단말(1103 포함) 기준 `110x↔1201` 1:1 코덱 정책·착신 BYE 재검증.
3. **W3(H1 권장, 서버/OPS)**: OPS의 `has_video`를 재사용해 영상 있는 채널만 `ConfbridgeSetSingleVideoSrc` 대상으로 지정(또는 더미 폴백) — **브리지 영상 소스 보장**. A10은 SIP 단말이라 서버 반영 필수.
4. **W4**: 결과 문서 갱신·커밋·`origin` push(별도 지시 없으면 NAS 제외).

## 5. 리스크·제약

- **AMI 활성화**: 보안 표면 증가 → 로컬 바인드·최소 권한·비밀정보 비커밋 필수. 컨테이너 재생성 필요.
- **H4(sfu)**: A10 `max_video_streams=1` 제약·6000 회귀로 이번 범위 제외.
- **H6**: WebRTC(no-video/recvonly leg) ↔ A10(H.264) 간 서버 전송 제약 → 클라이언트만으로 완결 불가할 수 있음(서버 SDP/포맷 정합 필요).
- **배포**: NAS `dev/prd` push/배포 없음. 네트워크·정책 변경 시 별도 지시.
