## 4. 실패/우회한 항목과 원인·해결

1. **`brew install cocoapods` (최초 시도)**: Tier 3 소스 빌드(z3/llvm/rust/ruby)로 수십 분 소요·락 충돌. 중단하고 기존 rbenv Ruby 3.3.0 + gem cocoapods 1.17.0 재사용으로 우회. `/usr/local/bin/pod` 심볼릭 링크 추가.
2. **`sudo` 필요 단계(Xcode 라이선스 accept/runFirstLaunch)**: sudo 비밀번호 미보유. 기존 Xcode 상태가 `[✓]`로 정상이라 스킵. 필요 시 비밀번호 제공 후 재실행.
3. **`flutter run -d macos` 실기**: `Failed to foreground app; open returned 1` / `Lost connection to device.` GUI 포그라운드 실패로 SIP 등록 로그 미확인. 빌드 산출물은 정상. (선택 항목 A7/A8 미달)
4. **Android toolchain**: cmdline-tools 미설치 유지(범위 밖).
