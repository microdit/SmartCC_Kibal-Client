[동기화 스크립트]
- ./scripts/git-pull.sh --interactive
    전체 브랜치 목록 + 선택, 작업트리 더티 시 자동 stash 후 checkout → pull
- ./scripts/git-push.sh --interactive
    전체 브랜치 최신 커밋/날짜 표시 + (LATEST) 표시, 브랜치/remote 대화형 선택 → push
    --dry-run 옵션으로 실제 push 없이 탐지/선택만 확인 가능
- ./scripts/git-sync.sh "커밋 메시지" --no-deploy
    커밋 + github/dev/prd 3-way push

[stash 복구]
- git stash pop   (자동 stash 메시지: git-pull.sh / git-push.sh auto-stash ...)
