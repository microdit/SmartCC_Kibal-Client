# macOS 단말 빌드 가이드 (v1.0)

## 3. 다른 Mac에서 직접 빌드 (권장 — Gatekeeper 경고 없음)

### 3.1 빌드 스크립트 (`macos-client/scripts/`)

- `./scripts/build_macos.sh [debug|release] [--no-dmg]`
  - Flutter 빌드 후 DMG 생성 (`macos_client_vX.Y.Z.dmg`)
- `./scripts/release_macos.sh [--no-bump] [--skip-tests] [--commit] [--install]`
  - 버전 결정 → `flutter pub get` → `flutter analyze`/`test` → Release 빌드 → DMG → 점검 → 체크섬 → (선택) 커밋·태그·설치

### 3.2 빌드 사용법 (권장)

```bash
cd macos-client && ./scripts/build_macos.sh release
```

- `debug` / `release` 인자로 빌드 설정
- `--no-dmg` 사용 시 DMG 생성 생략
- `--no-bump` 사용 시 release 스크립트가 현재 pubspec 버전 그대로 빌드

### 3.3 빌드 산출물 / 설치

- DMG: `macos-client/build/macos/Build/Products/Release/macos_client_vX.Y.Z.dmg`
- 앱: `macos-client/build/macos/Build/Products/Release/macos_client.app`
- 설치: `open /Applications/macos_client.app`

## 빌드 명령 요약

| 목적 | 명령 |
|------|------|
| Release 빌드 + DMG 생성 | `cd macos-client && ./scripts/build_macos.sh release` |
| Release 빌드 + DMG + 검증 (버전 그대로) | `cd macos-client && ./scripts/release_macos.sh --no-bump` |
| Debug 빌드 | `cd macos-client && ./scripts/build_macos.sh debug` |
| DMG 생성 안 함 | `cd macos-client && ./scripts/build_macos.sh release --no-dmg` |
| 릴리스 + 설치 | `cd macos-client && ./scripts/release_macos.sh --no-bump --install` |
