방식 선택 — 보안이관건
안1 (권장): 핵심만 포트포워딩 + OPS는 VPN
- IPTime2에서 8088/TCP, 10000-10200/UDP → 192.168.0.3 포워딩 (SIP 통화용)
- OPS 8091은 외부에 열지 말고 WireGuard/Tailscale VPN으로 접근 (docker exec 노출 차단)
- 외부 SIP 클라이언트는 ws://<공인IP或DDNS>:8088/ws 사용
안2: 전부 포트포워딩 — 8091도 열기. 간단하지만 OPS가 인터넷에 노출 → 비권장 (IPS/방화벽 + 강한 비밀번호 필수)
안3: 전량 VPN — 가장 안전하지만 외부 SIP 클라이언트(모바일 등)가 VPN 가입 필요 → 통화용에는 부적합

1. 토폴로지 확정: IPTime2 관리페이지(192.168.0.1)에서 WAN IP 확인

2. DDNS 설정: 공인 IP가 동적이면 IPTime2의 DDNS 기능으로 도메인 확보 (또는 ISP 고정 IP 문의)
3. IPTime2 포트포워딩: 8088/TCP, 10000-10200/UDP → 192.168.0.3 (안1이면 8091 제외)

6. 검증: 외부망(휴대폰 테더링 등)에서 nc -zv <공인IP> 8088 → 앱 등록 → 1:1/3자 통화, audioBytes>0
