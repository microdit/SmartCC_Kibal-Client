## 4. 영속 운영 규칙 (공통, 강제)

### 4.1 작업 시작 전 체크리스트
1. `wiki/04_Prompts/`에서 준수 지시서 확인.
2. 본 `docs/작업지시서.md` + `CLAUDE.md` + `docs/AGENTS.md` 포인터 확인.
3. NAS 작업 시 `wiki/09_Knowledge/20261127_NAS_접근경로_영속기록_v1.0.md` 확인.
4. `git status --short`, `git branch --show-current`, `git log --oneline -3` 확인.
5. 서버 파괴적 작업은 active call 확인 후 진행. active call > 0이면 BLOCKED.
6. "진행해" 승인은 위 규칙 준수 전제.

### 4.2 4환경 승격 규약
- 검수 전 변경은 **TEST** 작업브랜치(`test/<topic>`)에만 커밋/푸시.
- 검수 PASS 증거(analyze/test/DMG/SHA256/실기 로그) 확보 후 **DEV** 승격.
- **PRD/EXTERNAL**은 DEV 안정화 + 별도 승인 후 승격.
- DEV/PRD/EXTERNAL 기준선 직접 push 금지. 긴급 시 사용자 승인 필요.
- `git add -A` 금지. `git status --short` 후 명시 파일만 stage.
- NAS `dev/prd` remote 미도달 시 SKIP 사유 기록, 성공처럼 보고 금지.

### 4.3 Server-Client 교차 문서 동기화
- 양쪽 영향 사항은 같은 날짜 로그를 양쪽 repo에 기록:
  - Client: `wiki/07_Logs/YYYYMMDD_Server-Client_교차진행로그.md`
  - Server: `SmartCC_Kibal/wiki/07_Logs/YYYYMMDD_Server-Client_교차진행로그.md`
- 상세는 해당 repo, 상대 repo는 요약+경로+커밋 해시.

### 4.4 언어
- 특별 지시 없으면 한국어로 응답·문서·로그·커밋 메시지 작성.
- 코드 식별자/명령어/기술 용어는 원문 유지, 설명은 한국어.

### 4.5 릴리스/DMG 규칙
- **DEV/PRD 승격 또는 배포용 DMG**: `pubspec.yaml` 버전/빌드번호 상향(`vX.Y.Z+N`), `release_macos.sh` 빌드, 커밋/푸시/필요 원격 동기화, SHA256/버전/해시/태그 보고.
- **TEST 검수용 DMG 예외**: `test/*` 브랜치 검수 전용 빌드는 `--no-bump` 허용. 버전/태그/DEV·PRD 승격 동기화는 생략하되, 브랜치·커밋 해시·DMG 경로·SHA256·검증 결과를 보고하고 DMG 산출물은 git에 커밋하지 않는다. PASS 후 DEV 승격 시 정식 버전 발행 규칙 적용.
- **버전 사고 방지**: `git fetch --all --prune` 후 remote/tag/선행 확인. 선행 보존 + 버전 상향, 역행 덮어쓰기 금지. 승인 없는 force push 금지.

### 4.6 발행/원격 브랜치 보고 (강제)
- **클라이언트 코드/빌드/문서 작업 후 보고에는 아래 블록을 반드시 포함**한다. 누락 금지.
- 필수 7항목: 저장소 경로, 작업 브랜치, 원격 이름+URL, 푸시 원격 브랜치, 커밋 해시(짧은 해시+제목), 버전(`pubspec.yaml`/`Info.plist`), DMG 경로+SHA256.
- 추가 필수: 승격 상태(TEST 검수 중/PASS 후 DEV 승격/승격 완료), NAS dev/prd 반영 또는 SKIP(사유), 다른 작업자 pull 안내.
- 보고 템플릿/상세 규칙: `wiki/03_Guides/20261127_클라이언트_발행_원격브랜치_보고_규칙_v1.0.md`

```text
[클라이언트 발행 보고]
- 저장소: /Users/microdit/Downloads/dev/SmartCC_Kibal-Client
- 원격: <이름> (<URL>)

- NAS dev/prd: 반영 또는 SKIP(사유)
```

### 4.7 NAS 접근
- SMB: `//atom@nas2/NetBackup` → `/Volumes/NetBackup`.
- SSH: `nas2` = `192.168.11.2:4949`, 키 `~/.ssh/id_nas`. 에이전트 셸 timeout 가능하면 `ssh -G nas2`, `ssh -o ConnectTimeout=5 nas2 'echo OK'` 확인 후 SKIP 기록. 다른 포트 추측 금지.
