결론
- 1:1 실패의 직접 원인은 1101(macOS, 오디오 전용) 앱의 수신 라우팅 오류 GoException: no routes for location: /incoming로 착신 처리 불가 → 응답 없음/실패 종료(603 Decline 관측). 6000/6100 회의실 정상(양측 A/V 참여 확인)인 점과도 부합. (참고: 1102는 voiceOnly=false로 발신, 1101은 영상 미지원 단말이나 본 건은 라우트 예외 이전 단계에서 이미 중단됨)
조치 방향 (클라이언트, SmartCC_Kibal-Client)
- GoRouter에 /incoming 경로 등록 또는 수신 화면 네비게이션을 존재하는 경로/다이얼로그 방식으로 정정하고, 수신 이벤트(direction=incoming) → UI 전환 실패 시 예외 처리/폴백 추가 후 1101↔1102 1:1(음성/영상 협상 포함) 재검증 필요.
