SIP 영상통화 클라이언트 시작화면을 주소록(연락처) 목록으로 보이게 한다. OPS 로부터 연락처 정보, 인증 번호 정보 등 관련 정보를 자동으로 받아온다. 현재는 TLS 없이 데이터 주고 받고, 정상 동작확인되면 이후 보안 통신 형태로 바꾸는 수정계획을 가지도록한다.

설정 화면 창 따로 관리하자. 설정 화면창은 지금 론처(시작 창)로 구성을 바꾸면 되겠다.
설정 창은 사용자가 한번 설정 저장하면 그대로 유지 수정 전까지 유지. 인증 내선, OPS 클라이언트 키(수동 입력) 창에 인증키 넣고 엔터치면 서버와 데이터 검증하고 문제 없는지 확인시켜준다. 등록 후에는 계속 비밀번호 유지. 설정값 유지. 인증 상태 유지된다. 인증된 상태 유지표시. 새로 입력하면 지워지거나 바뀌는 것으로 처리한다. 10회 인증번호 틀리면 10회 오류되어서 초기화 된다고 표기해준다. 10회 도달하면 기존에 인증 관련해서는 초기화 된다. 다시 정확한 인증번호 입력이 될때까지는 미인증 상태이다.

시작화면 주소록(연락처)는 서버에서 자동으로 무조건 최신 정보 내려와서 보여진다.
빠른 연결 누르면 무조건 연결되게 비밀번호 정보까지 모두 가지고 있게한다.
