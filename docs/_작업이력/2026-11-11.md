- **서버 변경**: `pjsip.conf.template`(`media_address`, `external_*`, `local_net` 10/8, DTLS 옵션), `entrypoint.sh`(MEDIA_ADDRESS), `deploy/dev/compose.yaml`(bind mount), `.env`/`init-env.sh`(dev/prd)

## H5 규명 + v0.0.8 (re-INVITE 자동 수락)

- **입력**: 사용자가 `docs/테스트/오늘테스트로그_v1.4.md` 전달 (12:52~12:56, 1102/1103 다수 통화)
- **증거**: `evidence/20261111-124756-remote-audio/90_docker_during_test.log` (2.4MB, 같은 시간대)
  - 서버가 클라이언트로 re-INVITE 전송(`CSeq: 14230/18793 INVITE`), 클라이언트는 `100 Trying`만 보내고 **200 OK 없음**
  - re-INVITE SDP: `m=audio` + `m=video`(sendrecv) + `m=video`(sendonly), 모두 `c=192.168.11.39` + `a=candidate ... 172.19.0.2 ...`
  - 후보 보정은 정상 적용 중이었음 (영상도 `c=`로 치환됨)
  - 서버는 영상 RTP를 **수신**(`Got RTP ... type 100`)하지만 re-INVITE 미응답 상태에서 **송신 0건**
- **원인**: `macos-client/lib/src/sip/sip_client.dart:573` `onNewReinvite(ReInvite event) {}` 빈 구현
  - `sip_ua`는 앱이 `event.accept()`를 호출해야 200 OK(answer)를 전송
  - 미응답 → 새 ICE 세대 미완료 → 15~17초 후 `408 ICE Connection Failed` → BYE
  - 오디오 단독은 re-INVITE가 없어 118초 유지
- **수정**:
  - `sip_client.dart`: `onNewReinvite`에서 `event.accept({})` 자동 호출 + 로그, `_acceptReinvite` 추가
  - `packages/sip_ua/.../rtc_session.dart`: `upgradeToVideo`가 re-INVITE마다 중복 video track 추가하던 문제 방지(이미 로컬 video 있으면 skip)
  - `scripts/build_macos.sh`: `CFBundleVersion`도 pubspec `+build`와 동기화
- **검증**: `flutter analyze` 0건, `flutter test` 통과
- **v0.0.8+8 DMG**: `macos-client/build/macos/Build/Products/RELEASE/macos_client_v0.0.8.dmg`
  - sha256 `5cede9e01d2d5f760e46d13f252a93009e0982a91692e274fad088425f869993`
  - Info.plist `0.0.8` / build `8`, 엔타이틀먼트 `network.server` 포함, AOT에 `_acceptReinvite`/skip 로그 심볼 확인
- **잔여**: v0.0.8 3대 설치 후 영상/3자 5분 이상 재검증, `Sent RTP type 100` 확인, 3자 1명 튕김 확인
