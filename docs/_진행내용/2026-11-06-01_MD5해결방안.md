"환경 설정: 불완전 (MD5 해시 유지로 인해 테스트 불가)" 의미 설명
이 문구는 현재 Docker 환경 구성이 완전히 갖춰져 있지 않으며, 이로 인해 SIP 등록 테스트가 진행될 수 없는 상태를 의미합니다.

상세 의미
구성 요소	현재 상태	문제점
Docker env vars	SIP_PASSWORD_1101=21b570670b1eec59ad5b90b76ee3a03b (MD5 해시)	Asterisk는 plain text(1101pass)를 expecting하지만, client가 MD5 해시 전송
Asterisk 설정	plain text 비밀번호(1101pass 등) 적용됨	클라이언트가 올바른 형식(plain text)을 보내지 않음
SIP 등록 테스트	❌ 불가	401 인증 오류 반복, 등록 실패
왜 이런 상황이 발생하는가?
초기 원인: Docker 컨테이너 기동 시 환경 변수가 기본값(MD5 해시)으로 설정되어 있음

SIP_PASSWORD_1101=21b570670b1eec59ad5b90b76ee3a03b (32자리 16진수 해시 값)
문제 발생:

SIP.js 등 클라이언트는 기본적으로 environment variable SIP_PASSWORD_1101을 읽음
이 값이 MD5 해시이면, client는 해시 값을 그대로 전송
Asterium는 plain text 비밀번호를 expecting하지만, hash 값을 받음
결과: 401 Unauthorized 오류 발생
영구성 문제:

/opt/kibal/config/pjsip.conf.template에 ${SIP_PASSWORD_1101} 플레이스홀더가 있어
컨테이너 재시작 시 environment variable 값에 따라 자동 재생성됨
수동으로 /run/asterisk/pjsip.conf를 수정해도 컨테이너 재시작 시 초기화됨
왜 테스트가 불가한가?

테스트 시나리오: 1101 번호 SIP 등록 시도

1. Web Client 또는 node.js 스크립트 구동
2. environment variable SIP_PASSWORD_1101 읽기 (MD5 해시 값)
3. SIP REGISTER 메시지 전송 (MD5 해시 포함)
4. Asterisk 수신 → "expected plain text, got MD5 hash" → 401 오류
5. registration Unregistered 상태 유지
6. 재시도해도 동일 결과 → 테스트 포기하거나 우회 필요

Docker 유지하면서 MD5 해시 문제 영구 해결 방법
핵심 원인 재확인
MD5 해시 문제가 발생하는 이유는 Docker 환경 변수가 permanent하게 유지되기 때문입니다:

현재 상태: SIP_PASSWORD_1101=21b570670b1eec59ad5b90b76ee3a03b (MD5 해시)
문제점: 컨테이너 재시작해도 이 값이 유지되어 /run/asterisk/pjsip.conf가 매번 MD5 해시로 재생성됨
결과: Asterisco plain text(1101pass)를 expecting하지만, MD5 해시 전송 → 401 인증 실패

Step 2: Template 파일 permanent 수정 (/opt/kibal/config/pjsip.conf.template)
이 단계가 가장 중요합니다. template 파일이 수정되지 않으면 컨테이너 재시작 시 env vars 값과 상관없이 template의 ${SIP_PASSWORD_1101} 등이 유지되거나 기본값으로 돌아가기 때문입니다.

방법: Python 스크립트 파일 생성 및 실행 (이미 한 적 있음)


# /tmp/fix_template.py 내용 (이미 만들어짐)
import sys
with open("/opt/kibal/config/pjsip.conf.template", "r", encoding='utf-8') as f:
    content = f.read()
# Replace all password placeholders with plain text
replacements = [
    ("${SIP_PASSWORD_1001}", "1001pass"),
    ("${SIP_PASSWORD_1002}", "1002pass"),
    ("${SIP_PASSWORD_1003}", "1003pass"),
    ("${SIP_PASSWORD_1004}", "1004pass"),
    ("${SIP_PASSWORD_1101}", "1101pass"),
    ("${SIP_PASSWORD_1102}", "1102pass"),
    ("${SIP_PASSWORD_1103}", "1103pass"),
    ("${SIP_PASSWORD_1104}", "1104pass"),
]
for placeholder, password in replacements:
    content = content.replace(placeholder, password)
with open("/opt/kibal/config/pjsip.conf.template", "w", encoding='utf-8') as f:
    f.write(content)
print("Template modified successfully")

수정 후(template) 확인:
